## 200자 이내 소개

상태: `최종 확정`

> 독성 먼지로 지상이 폐쇄된 미래, 인류는 공기 정화층이 작동하는 지하 999m에 도시를 세웠다. 휴먼·버그본·AI 로봇의 영웅을 조작해 상대에게 보이지 않는 30초 동안 땅굴을 파고 광석과 진군로를 확보하라. 개전 후 자동 진군대와 고철 시설로 적의 길을 끊고 거점을 파괴하라. 캠페인·AI 대전·방 코드 1:1 온라인을 지원하는 실시간 전략 액션 게임.

- 글자 수: 198자(공백·문장부호 포함)

## 게임 플레이 방법

- 상태: `게임 내 상세 교본 반영 완료`
- 위치: 메인 메뉴 → `05 게임 플레이 방법`
- 진입 구조: `빠른 시작` 기본 탭에서 첫 경기 4단계와 필수 조작 확인 → `상세 교본`에서 전체 규칙 확인
- 심사 권장 모드: `컴퓨터와 대전 → 비밀 굴착전 → 1:1`

### 심사위원 빠른 시작

1. 영웅과 Q/R 아이템을 고르고 비밀 굴착전을 시작한다.
2. 준비 30초 동안 적 거점 방향으로 클릭하거나 WASD를 눌러 초고속으로 땅을 판다. 광석을 캐면 건설용 크레딧을 얻는다.
3. `A 설정`·`B 설정`에서 열린 길의 경유점을 순서대로 찍고 적용한다. 빠르게 지정하려면 커서를 목적지에 두고 Ctrl+1 또는 Ctrl+2를 누른다.
4. 개전 후 `균등 50/50`, `A 집중 75/25`, `B 집중 25/75` 중 다음 WAVE 배분을 고른다.
5. 영웅과 자동 진군대로 적 방어막을 먼저 제거하고 코어 HP를 0으로 만들면 승리한다. 4분이 끝나면 코어 비율, 방어막 비율 순으로 판정한다.

### 핵심 조작

- 이동·굴착: 마우스 클릭 또는 WASD/방향키
- 공격: 적 클릭, 현재 위치 강제 공격은 Ctrl+클릭
- 기술: `1·2` 일반 기술, `3` 필살기, `4` 고유 범위 굴착
- 생존·지형: `Shift` 생존 행동, `E`를 누른 뒤 클릭해 땅 메우기
- 아이템: `Q/R`, 컴퓨터 대전은 슬롯마다 2회 사용
- 건설: `B` 메뉴, Ctrl+Z/X/C/V/B/N/M 설치·관리, Ctrl+A/S/D/F/G/H/J 전술·성장
- 카메라: 우클릭 드래그 이동, `Space`로 영웅에게 복귀
- 메뉴: `Esc`; 컴퓨터전·캠페인은 일시정지되지만 온라인은 멈추지 않음

### 모드별 차이

- 비밀 굴착전: 준비 30초 동안 상대 굴착은 보이지 않는다. 적 거점 또는 상대 터널과 연결하지 못한 한 팀은 개전 시 패배한다.
- 개방 전선전: 준비 없이 열린 전장에서 즉시 전투·굴착·건설하며 시간 제한이 없다.
- 캠페인: 각 장 브리핑의 전용 목표와 실패 조건이 우선한다.
- 같이하기: 로그인 없이 6자리 방 코드로 1:1 접속하며 온라인에서는 개인 Q/R 아이템과 일시정지를 지원하지 않는다.

게임 안의 교본에는 A/B 상세 경로, 터널 권한, 크레딧·설치 제한, 전술지원·연구, 아이템·회복, 시야·미니맵과 모바일 가로 조작까지 수록한다.

### 최종 생성 프롬프트 요약

유승천 콘셉트를 참조해, 320×180에서도 읽히는 고대비 16:9 도트 키비주얼을 만든다. 큰 유승천 한 명이 화면 중앙에서 거대한 청색 드릴로 흙벽을 폭발시키고 벽 너머에는 실제 버그본 거점을 닮은 비대칭 군체 코어 하나만 둔다. 군체는 가시·알집·뿌리·뼈와 독성 황록 발광을 사용하며 붉은 원형 문·사원·국가 상징처럼 보이는 대칭 구조는 금지한다. 좌상단은 로고 공간으로 비우고, 진군대·포탑·다른 캐릭터·UI·글자·워터마크는 넣지 않는다.
