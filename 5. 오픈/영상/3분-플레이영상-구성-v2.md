# 서울 지하 999M — 3분 플레이 영상 구성 v2

- 목표 길이: 2분 56초
- 방향: 시네마틱 소개 대신 실제 굴착·진격·교전 화면 위에 나레이션으로 게임을 설명한다.
- 음성: 핵심 설명은 AI 나레이션, 자막은 화면 이해를 돕는 짧은 키워드만 사용한다.

## 구간

| 완성본 | 내용 | 편집 방향 |
|---:|---|---|
| 00:00–00:20 | 게임 소개 | 굴착 5초 뒤 공격 개시와 부대 교전으로 빠르게 전환 |
| 00:20–01:46 | 실제 플레이 | 30초 준비, 자동 진격, 영웅·부대·시설 전투, 거점 압박 |
| 01:46–01:58 | 지휘관 | 서로 다른 실제 전투 장면 3개 |
| 01:58–02:33 | 캠페인 | 캠페인 지도, 임무 선택, 도입, 실제 전투, 작전 성공 |
| 02:33–02:48 | 온라인 | 방 설정·준비와 온라인 1:1 시작 |
| 02:48–02:56 | 엔드 카드 | 게임명과 공개 플레이 주소 |

## 나레이션 원칙

- 게임 원음은 유지하되 나레이션 중에는 자동으로 낮춘다.
- 화면에 이미 보이는 내용을 그대로 읽지 않고 규칙과 의도를 설명한다.
- 문장 사이에 게임 소리만 들리는 구간을 남겨 과도한 설명을 피한다.
- 전체 자막 대신 `직접 굴착`, `부대 자동 진격`, `스테이지형 캠페인` 같은 핵심어만 표시한다.
