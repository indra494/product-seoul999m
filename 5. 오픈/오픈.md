# 공개 및 제출

게임의 외부 공개, 배포, 시연과 해커톤 제출 결과물을 관리한다.

## 공개 상태

- 게임 제목: `서울 지하 999M / SEOUL: 999M BELOW`
- 장르: `땅굴 개척형 실시간 전략 액션 / Tunnel-Building Action RTS`
- 공개 플레이 URL: https://play.udra.co.kr
- 링크 상태: `HTTPS 200 응답 확인 / 실제 브라우저 플레이·온라인 완주 검증 필요`
- 확인일: 2026-08-26
- 게임 제출본 상태: `2026-08-26 기능 동결 / 이후 신규 게임 수정 없음`
- 로컬 후보 검증: `프로덕션 빌드 포함 전체 94/94 통과, ESLint 오류 0건`

제출용 확정 자료는 `5. 오픈/제출/해커톤-제출-패키지.md`를 기준으로 한다.

## 제출 전 남은 운영 작업

1. 최신 동결 빌드를 공개 URL에 배포한다.
2. 외부 브라우저에서 첫 진입, 게임 플레이 방법, 컴퓨터 대전과 방 코드 온라인 완주를 확인한다.
3. Codex 활용 설명을 완성한다.
4. 제출 폼에 확정 자료를 입력하고 링크·썸네일·영상 접근 권한을 마지막으로 확인한다.

위 작업은 제출 운영 범위이며 게임 기능 변경이 아니다. 공개 플레이를 막는 치명적 오류가 없다면 현재 게임을 그대로 제출한다.
