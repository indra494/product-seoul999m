## 1. 현재 판단

현재 데모는 핵심 아이디어를 검증하는 단계까지 도달했다. 플레이어가 흙을 파고, 자동 굴착대가 열린 땅굴을 따라 이동하며, 영웅·포탑·거점이 교전하는 기본 루프는 작동한다.

그러나 제목과 브랜드, 첫 화면, 캠페인, 네트워크, 미니맵, 진군 경로 지정, 생존 코어 방어막, 완성형 그래픽과 건설 인터페이스는 아직 없다. 따라서 현재 상태는 `플레이 가능한 핵심 프로토타입`이며 `제출 가능한 완성 게임`은 아니다.

### 0단계 — 범위와 정체성 고정

상태: `[다음 작업]`

작업:

3. 제출 버전에서 캐릭터를 한 명만 완성할지 두 명 이상 만들지 결정한다.

완료 기준:

- 제목, 로고 방향, 한 줄 소개와 제출 범위가 문서에 `확정`으로 기록된다.

### 1단계 — 게임 규칙과 코드 구조 고정

선행조건: 0단계

작업:

1. 화면 코드에 섞인 게임 계산을 독립 시뮬레이션 모듈로 분리한다.
2. 생존 코어에 방어막과 본체 체력을 분리한다.
3. 영웅, 자동 굴착대, 포탑별 공격 권한을 적용한다.
4. 웨이브, 경제와 승패 수치를 한 곳의 설정 데이터로 이동한다.

완료 기준:

- 자동 굴착대가 방어막을 깨기 전에는 영웅이 코어 본체를 공격할 수 없다.
- 기존 이동·굴착·전투·AI가 회귀 테스트를 통과한다.
- 같은 시뮬레이션을 캠페인, AI 연습과 네트워크에서 재사용할 수 있다.

### 2단계 — 대표 전략 시스템 완성

선행조건: 1단계

작업:

1. 미니맵을 구현한다.
2. 플레이어가 열린 땅굴 위에 최대 4개의 진군 경로와 중간 지점을 지정한다.
3. 실제 필드와 미니맵에 경로별 색상 가이드라인을 표시한다.
4. 자동 굴착대를 활성 경로에 균등 분배한다.
5. 경로가 막힌 유닛은 5초 대기 후 거점 회수 연출과 함께 제거한다.

완료 기준:

- 플레이어가 만든 둘 이상의 경로로 굴착대가 나뉘어 이동한다.
- 굴착·매립으로 경로를 바꾸면 다음 이동부터 반영된다.
- 미니맵만 봐도 아군 진군 상태와 발견된 지형을 판단할 수 있다.

추가 성장 수직 슬라이스:

- [x] 자동 진군대 파쇄병·호위병·사격병 공통 로직과 좁은 통로 혼잡 굴착
- [ ] 14초 4명 웨이브와 팀당 12명 제한 플레이 테스트
- [ ] 진군대 웨이브 기반 3단계 성장
- [ ] 공통 방어력·치명타 판정과 전투 피드백
- [ ] 영웅 1~6레벨과 유승천 3·5레벨 2지선다

### 3단계 — UI와 아트 수직 슬라이스

선행조건: 0단계, 2단계의 화면 요구사항

작업:

1. 로고가 나오는 오프닝과 메인 메뉴를 만든다.
2. HUD, 기술, 체력, 방어막, 크레딧, 웨이브와 건설 UI를 재설계한다.
3. 유승천의 상하좌우 대기·이동·공격·피격·전투불능·부활 스프라이트를 만든다.
4. 흙, 암반, 기반암, 열린 땅굴과 균열 단계를 새 타일셋으로 교체한다.
5. 볼트 포탑과 차단벽에 서로 다른 외형·공격·파괴 연출을 적용한다.
6. 건설 시 미리보기, 설치 가능 여부와 범위를 표시한다.

완료 기준:

- 스크린샷 한 장만으로 임시 프로토타입이 아니라 동일한 게임의 완성된 시각 방향으로 보인다.
- 캐릭터의 방향과 현재 행동을 즉시 구분할 수 있다.
- 각 포탑의 역할을 외형과 효과만 보고 구분할 수 있다.

### 4단계 — 캠페인 첫 임무와 저장

선행조건: 1~3단계

작업:

1. 프롤로그 스토리와 첫 임무 목표를 작성한다.
2. 3~5장의 도트 일러스트와 화면 이동으로 짧은 오프닝을 만든다.
3. 첫 임무에 이동, 굴착, 경로 지정, 호위와 방어막 파괴를 순차적으로 가르친다.
4. 클리어 기록, 이어하기와 설정을 브라우저에 저장한다.

완료 기준:

- 처음 접속한 사용자가 설명 없이 첫 임무를 시작하고 핵심 규칙을 학습한다.
- 새로고침 후에도 캠페인 진행 상태와 설정이 유지된다.

### 5단계 — 함께하기 1대1

선행조건: 1단계의 독립 시뮬레이션

작업:

1. 방 만들기와 방 코드 참가 화면을 만든다.
2. 서버가 이동, 굴착, 공격, 자동 유닛, 포탑, 방어막과 승패를 판정한다.
3. 클라이언트는 입력을 보내고 서버 상태를 보간해 그린다.
4. 양쪽 플레이어에게 자기 시야에 맞는 상태를 표시한다.
5. 연결 종료, 상대 이탈과 경기 종료 처리를 추가한다.

완료 기준:

- 서로 다른 두 브라우저에서 같은 방에 참가해 한 경기를 끝낼 수 있다.
- 굴착 타일, 유닛 위치, 체력과 승패가 양쪽에서 일치한다.
- 연결 지연에도 캐릭터 이동과 기본 공격이 플레이 가능하다.

### 6단계 — 밸런스, 품질과 제출

선행조건: 1~5단계

작업:

1. 한 판이 3~6분 안에 끝나도록 수치를 조정한다.
2. PC와 모바일의 조작, 화면 비율과 성능을 확인한다.
3. 캠페인, AI 연습과 함께하기의 시작·승리·패배·재시작을 테스트한다.
4. 효과음, 화면 흔들림, 파편과 피격 피드백을 정리한다.
5. 제출 소개, 플레이 방법, 시연 순서와 공개 빌드를 준비한다.

완료 기준:

- 치명적 오류 없이 캠페인 첫 임무와 네트워크 한 경기를 완료한다.
- 첫 30초 안에 굴착, 진군 경로와 승리 목표를 이해할 수 있다.
- 3분 시연에서 게임의 차별점이 드러난다.

## 6. 상대적 일정표

정확한 마감일까지 남은 일수에 따라 하루 단위는 조정하되 순서는 바꾸지 않는다.

| 순서 | 목표 | 권장 구간 | 현재 상태 |
|---|---|---:|---|
| 0 | 제목·브랜드·범위 동결 | 시작 반나절 | 다음 작업 |
| 1 | 시뮬레이션 분리·방어막 | 1일 | 미착수 |
| 2 | 미니맵·진군 경로 | 1~1.5일 | 미착수 |
| 3 | 메뉴·HUD·캐릭터·타일·건설 UI | 1.5~2일 | 12명 선택·출전 1차 적용, 개별 고급 액션 보강 중 |
| 4 | 캠페인 첫 임무·저장 | 1일 | 미착수 |
| 5 | 방 코드 네트워크 1대1 | 1.5~2일 | 미착수 |

총 예상량은 7~9일이다. 실제 남은 시간이 이보다 짧다면 3단계에서 캐릭터 한 명만 완성하고, 4단계의 오프닝을 정지 이미지 3장으로 줄이며, 재접속과 두 번째 포탑은 제외한다.

## 7. 의존성과 가장 큰 위험

1. 네트워크는 1단계의 시뮬레이션 분리 없이는 시작하지 않는다.
2. 진군 경로 UI는 미니맵과 함께 설계해야 중복 작업을 피할 수 있다.
3. 여러 캐릭터와 여러 맵은 아트 제작량을 폭발시키므로 제출 범위에 넣지 않는다.
4. 캠페인 영상은 풀 애니메이션이 아니라 짧은 모션 코믹으로 제한한다.
5. 새로운 기능을 추가하면 Must have 목록에서 같은 규모의 항목 하나를 제거한다.
