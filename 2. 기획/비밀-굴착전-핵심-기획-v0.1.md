# 비밀 굴착전 핵심 기획 v0.1

## 1. 문서 상태

- 상태: `확정 / 구현·자동 검증 완료`
- 결정일: 2026-08-26 최종 착수 승인
- 실행 조건: 기준 커밋 `2fa1f5c` 위에서 기존 모드 회귀를 보존하며 구현한다.
- 관계: 신규 기본 대전 후보는 `비밀 굴착전`, 기존 대전은 별도 `개방 전선전`으로 보존한다.

## 2. 핵심 경험

`상대가 보이지 않는 2분 동안 비밀 공격로를 파고, 개전과 함께 밝혀진 자기 터널망으로 A/B 진군을 지휘한다.`

## 3. 경기 구조

1. `준비 2분`: 팀 전용 굴착, 광석·골드 확보, 방어 준비와 A/B 공격로 설계
2. `지반 고정`: 추가 굴착·매립과 4번 지형 행동 중지, 팀별 유효 터널망 판정
3. `침공 4분`: 영웅과 진군대가 자기 팀 전용 터널과 공동 터널을 사용해 상대 거점을 공격
4. 코어 파괴를 우선하며, 제한 시간 종료 시 남은 코어 본체 비율→남은 방어막 비율을 비교하고 둘 다 같으면 무승부로 처리한다.

## 4. 준비 단계 시야 규칙

- `확정`: 양 팀 거점의 정확한 위치는 경기 시작부터 전장과 미니맵에 항상 표시한다.
- `확정`: 플레이어는 자기 영웅과 아군 영웅만 볼 수 있다.
- `확정`: 상대 영웅은 거리와 일반 시야 판정에 관계없이 완전히 숨긴다. 캐릭터 본체, 이름표, 체력 바, 미니맵 표식과 위치를 직접 드러내는 기술 효과를 표시하지 않는다.
- `확정`: 상대 팀 전용 터널은 흙 또는 미확인 지형처럼 보이며 경로 형태를 공개하지 않는다.
- `확정`: 양 팀이 같은 타일을 파면 그 부분만 공동 터널 후보가 된다. 준비 중에는 접촉 격벽과 익명의 국소 진동 경고만 보여주며 상대 캐릭터와 상대 터널 전체는 공개하지 않는다.
- 필수 파생 규칙: 보이지 않는 적에게 공격받는 불공정을 막기 위해 준비 단계에는 양 팀 사이의 영웅 공격, 투사체 피해와 직접 충돌을 비활성화한다. 진군대 웨이브도 아직 출전하지 않는다.

## 5. 지반 고정과 개전 표시

- 2분 종료 시 `지반 고정 · 침공 개시` 전환 연출을 표시한다.
- 게임은 아군 거점과 연결되어 있고 자기 팀이 실제로 이동할 수 있는 타일을 `이용 가능 터널망`으로 판정한다.
- 이용 가능 터널망은 아군 거점부터 바닥 가장자리를 따라 켜지는 짧은 스캔 광원으로 한 번 읽어준다.
- 일반 이용 가능 터널은 얇은 아군색 테두리로 표시한다.
- 공동 터널은 황색 사선 또는 경고 무늬로 표시해 아군 전용 터널과 구분한다.
- 상대 팀 전용 터널은 개전 뒤에도 자동 공개하지 않으며 아군이 이용할 수 없다.
- 게임이 추천하거나 사용자가 지정한 주 공격로에는 색상만 사용하지 않고 문자와 화살표를 함께 표시한다.
  - `A`: A 표식과 채운 형태의 진행 화살표
  - `B`: B 표식과 윤곽 형태의 진행 화살표
- A/B가 아닌 이용 가능 터널과 막다른 길은 테두리만 남기고 진행 화살표를 표시하지 않는다. 따라서 플레이어는 `이동 가능`, `공동`, `현재 진군 방향`을 서로 혼동하지 않는다.
- A/B 진행 화살표는 거점에서 전방으로 흐르며 첫 갈림길, 전장과 미니맵에서 같은 표기를 사용한다.

## 6. 침공 단계 시야와 통행

- 전투가 시작되면 상대 영웅은 기존 전투의 일반 시야·안개 규칙에 따라 발견될 때만 표시한다. 개전만으로 상대 영웅 전체를 공개하지 않는다.
- 영웅과 진군대는 `자기 팀 전용 + 공동` 터널만 이용한다.
- 상대 전용 터널의 위치와 모양은 계속 비공개이며 통행할 수 없다.
- 준비 중 공동 터널을 막았던 접촉 격벽은 개전과 함께 해제되어 첫 교전 가능 지점이 된다.

## 7. A/B 진군 원칙

- 모든 열린 터널에 병력을 자동 분산하지 않는다.
- 게임이 유효 공격로를 탐지해 A/B 후보를 추천하고 사용자가 최종 선택한다.
- 진군 비율은 `균등 50:50 / A 집중 75:25 / B 집중 25:75`를 기본 후보로 둔다.
- 선택하지 않은 추가 터널은 영웅 이동, 광석 회수, 후퇴, 기만과 예비 공격로로 유지한다.

## 8. 유효 전선 연결 실패 — 확정

- 준비 2분의 필수 목표는 `유효 전선 연결` 한 개 이상을 만드는 것이다. 광석과 방어 시설에 집중할 수는 있지만 연결을 완전히 포기하는 순수 요새화는 승리 전략으로 인정하지 않는다.
- 내 팀의 유효 전선 연결은 아군 거점에서 끊김 없이 이어진 터널이 아래 중 하나를 달성했을 때 성립한다.
  1. 상대 거점의 침공 접속 범위에 직접 도달한다.
  2. 상대 거점까지 이어진 상대 팀 터널과 접촉한다.
- 두 팀의 터널이 접촉하면 접촉점 하나만 여는 것으로 끝내지 않는다. `아군 거점→접촉점→상대 거점`을 잇는 연속 핵심 구간만 `공용 전선 터널`로 전환해 양 팀 영웅과 진군대가 이동할 수 있게 한다.
- 접촉한 양쪽 터널의 광맥 지선, 기만로, 후퇴로와 막다른 길까지 전부 공개하거나 공용화하지 않는다. 공동으로 바뀌는 것은 두 거점을 연결하는 핵심 구간뿐이다.
- 준비 시간이 끝났을 때 직접 도달도, 상대 터널 접촉도 하지 못한 팀은 `굴착 작전 실패 · 고립 패배`로 처리한다. 병력 처치 수나 설치물 수로 이를 뒤집지 않는다.
- 양 팀 모두 유효 연결에 실패하면 어느 한쪽을 임의로 승리시키지 않고 `쌍방 작전 실패` 무승부로 처리한다.
- 유효 연결을 하나만 확보한 뒤 남은 시간과 자원을 광석·설치물에 투자하는 수비 중심 전략은 허용한다. 즉 수비 전략을 없애는 것이 아니라 최소한의 역습 가능성은 반드시 요구한다.
- 준비 종료 30초와 10초 전에 `유효 전선 미연결 · 종료 시 패배`를 크게 경고하고, 전장·미니맵에 적 거점 방향과 현재 연결 진행 상태를 표시한다.
- 신규 플레이어가 규칙을 몰라 2분 만에 전투도 못 하고 탈락하지 않도록 대표 맵의 최단 연결은 기본 굴착만으로 약 60~75초 안에 가능하게 조정한다. 남은 시간은 광석·우회로·방어 중 선택하게 한다.
- 유효 연결이 없는 팀에 자동 터널을 만들어 주지는 않는다. 첫 전투 안내와 진행 표시는 제공하되 최종 연결은 플레이어 행동의 결과로 남긴다.

## 9. 구현 기준 수치

1. 준비 단계는 정확히 120초이며 조기 개전은 사용하지 않는다.
2. 기본 접촉 굴착은 기존 개방 전선전보다 1.6배 빠르게 하고, 4번 굴착 행동은 준비 중 재사용 대기시간을 50%로 줄인다.
3. 준비 단계의 크레딧 획득·건설 비용·설치물 상한은 기존 대전 경제를 재사용한다. 별도 무료 수입이나 모드 전용 골드 상한은 추가하지 않는다.
4. 개전 뒤 240초가 지나면 남은 코어 본체 비율→남은 방어막 비율을 비교하고 둘 다 같으면 무승부로 처리한다. 굴착량·전선 길이·처치 수는 판정에 사용하지 않는다.
5. `지반 고정 · 침공 개시` 스캔은 전투 시간을 멈추지 않는 짧은 전환으로 두고 첫 웨이브는 개전 직후 출전한다.
6. 온라인도 화면상 위장만 하지 않고 방 상태·스냅샷에 규칙·페이즈·팀별 터널 접근 정보를 포함한다. 준비 중 상대 영웅과 상대 전용 터널은 수신 팀 화면에 노출하지 않는다.

## 10. 기존 모드 보존

- `개방 전선전`의 기존 지형, 4번 굴착 기능, 시야, 웨이브와 전투 규칙은 변경하지 않는다.
- `비밀 굴착전`은 자동 테스트와 실제 브라우저 검증을 통과한 메뉴 기본 선택이다. `개방 전선전`은 별도 선택지로 계속 제공한다.
