# 서울 지하 999M 공용 행동·아이템 슬롯 제안 v0.1

- 상태: 1차 확정·프로토타입 적용 / 2026-08-26 굴착기 광역화 보정
- 기준일: 2026-08-21
- 목적: 캐릭터 기술 정체성을 흐리지 않으면서 생존, 땅굴 복구와 소비 아이템 전략을 추가한다.

## 1. 기술 개수 판단

현재 전투 버튼은 캐릭터 기술 2개, 필살기와 굴착 기술의 총 4개다. 액션과 실시간 전략을 함께 처리하고 모바일까지 고려하면 공격 버튼을 더 늘리는 것은 권하지 않는다. 기술 수보다 각 기술의 용도와 판정 차이를 선명하게 만드는 편이 우선이다.

권고 구조는 다음과 같다.

- `1`, `2`: 캐릭터 고유 일반 기술
- `3`: 캐릭터 고유 필살기
- `4`: 캐릭터 고유 굴착 기술
- `E`: 모든 캐릭터가 사용하는 땅 메우기
- `Shift`: 캐릭터별 생존기 1개
- `Q`, `R`: 경기 중 구매한 소비 아이템 2칸
- 모바일: 고유 기술 4칸과 별도로 작은 공용 행동·아이템 줄을 둔다.

## 2. 공용 땅 메우기

- 모든 캐릭터가 인접한 열린 타일 하나를 흙벽으로 복구한다.
- 기술처럼 `E`로 지정 모드를 켜고 클릭한 타일에 즉시 생성한다. 별도 시전 게이지와 피격 취소는 사용하지 않는다.
- 타일당 흙 자원 또는 15크레딧을 소비한다.
- 캐릭터, 진군대, 설치물과 거점이 있는 칸은 메울 수 없다.
- 적 거점 3칸 안에서는 사용할 수 없다.
- 무제한 즉시 복구는 통로 봉쇄와 경기 지연을 만들기 때문에 금지한다.

## 3. 캐릭터별 생존기

모든 캐릭터에게 같은 회복 버튼을 주지 않고 역할에 맞는 생존기 한 개를 준다. 재사용 대기시간은 약 12~18초를 기준으로 한다.

- 스피드형: 짧은 무적이 있는 회피 또는 순간 이동
- 힘형: 경직 무시와 피해 감소
- 서포터: 자신과 가까운 아군의 소량 회복
- 탱커: 잠시 방어막 또는 밀치기 저항
- 버그본: 탈피, 흡혈 또는 짧은 잠복
- AI 로봇: 긴급 방열, 장갑 전개 또는 자가 수리

생존기는 공격 기술 슬롯을 차지하지 않는 별도 공용 위치에 표시하되, 효과는 캐릭터마다 달라야 한다.

## 4. 구매 아이템 1차안

### 벽 매설 폭탄

- 아군 거점에서 구매하고 한 번에 1개만 소지한다.
- 열린 길이 아니라 파괴되지 않은 흙벽에 매설한다.
- 1.25초 뒤 무장되며 적이 해당 벽을 굴착하면 폭발한다.
- 설치한 팀에게만 위치가 보인다.
- 폭발은 굴착자와 주변 한 칸에 피해·짧은 기절을 주며 벽도 크게 갈라지게 한다.

### 에너지 드링크

- 즉시 소량 회복하고 5초 동안 이동·굴착·공격 속도를 올린다.
- 연속 사용 시 지속 시간이 중첩되지 않는다.
- 전투 중 도주, 긴급 굴착과 마지막 코어 공략 중 하나를 선택하게 만드는 가격으로 맞춘다.

## 5. 재미와 위험

- 장점: 크레딧을 포탑에 쓸지 소모품에 쓸지 선택하게 되어 경기마다 다른 판단이 생긴다.
- 장점: 땅굴 자체가 함정과 복구의 대상이 되어 이 게임의 핵심 차별점이 강해진다.
- 위험: 메우기와 폭탄이 너무 싸면 수비만 하는 경기가 된다.
- 위험: 생존기를 공격 기술처럼 복잡하게 만들면 캐릭터 학습 부담이 급증한다.
- 검증 항목: 메우기 비용·시전 시간, 폭탄 최대 소지량, 에너지 드링크 가격과 강화 수치.

## 6. 권고 구현 순서

1. 공용 `E 땅 메우기`와 적 코어 3칸 제한을 HUD에 적용했다.
2. 12명을 회복·방어·회피 세 생존 유형으로 나눠 `Shift`에 적용했다.
3. 거점 근처에서 `Q` 벽 매설 폭탄과 `R` 에너지 드링크를 구매·사용하도록 적용했다.
4. 비용, 재사용 대기시간과 생존기 역할 배분은 플레이 테스트로 조정한다.

사용자 승인에 따라 이 문서를 공용 행동과 아이템의 1차 기준으로 사용한다.

## 8. 2026-08-21 확정 보정

- 아이템 구매는 왼쪽 보급품 메뉴에서 하며 아군 코어 3칸 안에서만 결제가 성립한다.
- Q/R 공용 슬롯은 합계 2칸이다. 같은 아이템을 두 개 넣는 것도 허용한다.
- E 땅 메우기는 클릭 즉시 타일을 생성하고 짧은 흙 분출·충격 연출만 사용한다.
- 회피형 Shift 생존기는 실제 진행 방향으로 짧게 이동하고 잔상을 남긴다.
- 자동 진군대의 머리 위 삼각형, 발밑 팀색 원과 개별 레벨 문자는 표시하지 않는다.
- 진군대는 작은 팀색 HP 바와 어두운 외곽선만 사용한다. 팀 명칭·삼각 표식은 영웅에게만 사용한다.
- 포탑은 하단 팀색 띠만 유지하고, 플레이어가 지정한 공격 대상만 금색 점선 링을 표시한다.
- 본 절이 앞선 구매 방식과 시각 표기 설명보다 우선한다.

## 9. 2026-08-21 지정 매립·점프형 생존기

- 확정: E는 즉시 전방을 메우지 않고 매립 지정 모드를 켜고 끈다.
- 확정: 지정 모드에서 영웅 반경 2칸 안의 현재 시야·열린 타일을 마우스로 클릭해 정확한 위치를 선택한다.
- 확정: 한 번 설치한 뒤에도 지정 모드는 유지하며 E, 우클릭 또는 ESC로 종료한다.
- 확정: 땅 메우기 재사용 대기시간은 1초다. 비용은 15크레딧이며 클릭 즉시 생성되어 적 접근 중 빠르게 통로를 봉쇄할 수 있다.
- 확정: 생존기 유형에 점프를 추가한다. 점프는 커서 방향 최대 3칸의 열린 착지점을 찾고 중간 흙벽 1칸을 넘을 수 있다.
- 확정: 점프 중에는 짧은 무적을 가지며 이동 궤적·공중 높이·착지 먼지로 구분한다.
- 1차 점프 캐릭터는 스피드형 휴먼 유승천과 날개형 버그본 회분이다. 나머지는 기존 회복·방어·회피 유형을 유지한다.

## 10. 2026-08-23 전투 전 장착·회복량 보정

- Q/R 아이템은 경기 중 구매하지 않고 전투 편성에서 두 개를 선택해 즉시 지급한다.
- 캠페인은 응급 수복팩과 복합 장갑판을 기본 장착한다.
- 에너지 드링크는 최대 HP 20%를 회복하고 5초 가속을 제공한다.
- 응급 수복팩은 최대 HP 90%를 즉시 회복한다. 위기 탈출용 1회 아이템답게 빈사 상태에서 사실상 전열 복귀가 가능해야 한다.
- 본 절이 앞선 구매 방식과 12%·35% 회복량 설명보다 우선한다.

## 11. 2026-08-23 거점 안전 회복

- 모든 영웅은 자기 팀 거점 중심 4.5칸 안에서 마지막 피격 후 4초가 지나면 초당 최대 HP 6%를 자동 회복한다.
- 피해를 받으면 즉시 회복이 중단되므로 거점 앞 교전 중 버티기 수단이 아니라 전선에서 물러난 영웅의 재정비 공간으로 사용한다.
- 컴퓨터 영웅과 온라인 양 팀에도 같은 규칙을 적용해 진영에 따른 회복 특혜가 생기지 않게 한다.
- 캠페인도 장별 별도 금지 규칙이 없는 한 같은 기본 회복 규칙을 사용한다.

## 12. 2026-08-25 압력 지뢰 전환 확정

- `벽 매설 폭탄`은 폐기하고 같은 `Q/R` 아이템 ID를 호환 유지한 채 표시 이름과 판정을 `압력 지뢰`로 바꾼다.
- 압력 지뢰는 흙벽이 아니라 영웅이 서 있는 열린 땅의 발밑에 설치한다. 설치 성공 뒤 아이템 한 칸을 소비한다.
- 설치 0.35초 뒤 적 접촉 감지를 시작한다. 적 유닛이 중심 0.72칸 안을 밟거나 설치 후 3초가 지나면 먼저 성립한 조건으로 폭발한다.
- 폭발은 중심 1.9칸 안의 적 영웅·진군대와 적 설치물에 광역 피해를 주고, 적 유닛에는 짧은 경직을 적용한다. 아군 피해는 없다.
- 마지막 약 0.85초에는 설치 팀에게 폭발 반경과 빠른 경고 점멸을 보여 대응 시간을 알린다. 적에게는 시야·소유권 규칙을 그대로 적용한다.
- 본 절이 4장의 벽 매설 폭탄 규칙과 6장의 기존 구현 순서보다 우선한다.

## 13. 2026-08-25 에너지 드링크·건설 입력 보정

- 에너지 드링크의 즉시 회복량은 최대 HP 20%에서 30%로 올린다. 5초 가속과 1회 소비 규칙은 유지한다.
- 전투 HUD의 건설 버튼에는 `B` 단축키를 명시한다. `B`는 건설 메뉴를 열고 닫으며, 메뉴에서 실제 설치물·강화·철거·전술지원을 선택한다.
- 이 절이 10절의 에너지 드링크 회복량과 기존 `B` 즉시 첫 설치물 선택 동작보다 우선한다.

## 14. 2026-08-26 전 영웅 4번 굴착기 광역화 — 확정

- 모든 영웅의 4번 지형 행동은 고유 패턴과 역할을 유지하되 직선·십자·분기·ㄷ자 패턴의 도달 길이와 원형·봉쇄 패턴의 반경을 기존의 약 1.5배로 확장한다. 격자 반올림으로 반경 1은 반경 2가 된다.
- 굴착 효과·애니메이션은 끝까지 재생하지만 시전자 이동을 약 1초 동안 막지 않는다. 입력 중복 방지를 위한 약 0.12초의 짧은 동작 잠금만 사용한다.
- 이 범위·경직 규칙은 캠페인, 개방 전선전, 비밀 굴착전, 컴퓨터 영웅과 온라인 영웅에 공통 적용한다.
- 비밀 굴착전 준비 단계에만 4번 재사용 시간을 원래의 25%로 줄인다. 침공 단계의 지반 고정과 다른 모드의 원래 재사용 시간은 유지한다.

## 15. 2026-08-26 건설 직접 단축키·특성 확인 — 최신 확정

- `B`는 전체 건설 메뉴를 열고 닫는 기능으로 유지한다.
- 종족별 다섯 설치물은 화면에 정렬된 순서대로 `5 / 6 / 7 / 8 / 9`를 배정한다. 메뉴를 먼저 열지 않아도 해당 키를 누르면 바로 배치 모드에 들어간다.
- 설치물 강화는 `U`, 철거는 `X`로 바로 선택한다. 모든 건설 메뉴 버튼에 실제 단축키를 함께 표기한다.
- 전투 HUD의 특성 버튼은 미선택 특성이 있으면 선택 창을, 모두 골랐으면 선택 내역을 연다. 이미 선택한 단계 탭에서는 선택한 특성의 이름과 실제 효과 설명을 다시 보여 준다.

## 16. 2026-08-26 건설 메뉴 14종 직접 단축키 — 최신 확정

- 15절의 `5~9 / U / X` 직접 선택은 이 최신 결정으로 대체한다. `B`의 건설 메뉴 열기·닫기는 유지한다.
- `Ctrl+Z / X / C / V / B`는 현재 종족의 설치물 1~5, `Ctrl+N`은 강화, `Ctrl+M`은 철거다.
- `Ctrl+Shift+Z / X / C / V / B`는 방어·공세·지역 타격·응급 회복·비상 증원, `Ctrl+Shift+N`은 진군대 연구, `Ctrl+Shift+M`은 정예병 예약이다.
- 단축키는 건설 메뉴를 먼저 열지 않아도 작동하며, 브라우저 기본 단축키보다 게임 명령을 우선한다.
- 건설 메뉴의 14개 항목에는 해당 조합을 항상 표시한다.

## 17. 2026-08-26 두 키 건설·전술 단축키 — 최신 확정

- 16절의 `Ctrl+Shift` 세 키 조합은 이 최신 결정으로 폐기한다. 모든 직접 명령은 `Ctrl + 문자 한 개`의 두 키 조합만 사용한다.
- 설치·관리 7종은 `Ctrl+Z / X / C / V / B / N / M`이다. 순서대로 설치물 1~5, 강화, 철거에 대응한다.
- 전술·연구 7종은 `Ctrl+A / S / D / F / G / H / J`다. 순서대로 방어, 공세, 지역 타격, 응급 회복, 비상 증원, 진군대 연구, 정예병 예약에 대응한다.
- 건설 메뉴에서는 축약하지 않은 `Ctrl+문자` 전체를 충분히 큰 글자로 표시한다. 작은 단축키 표식을 그림 위에 겹치지 않고 별도 열에 배치한다.
- 게임이 활성화된 동안 위 조합은 브라우저 기본 단축키보다 우선한다. 일반 `B`는 계속 건설 메뉴 열기·닫기다.

## 18. 2026-08-26 대전 아이템 생존력·전술 회복 보정 — 최신 확정

- 컴퓨터 대전의 Q/R에는 전투 편성에서 고른 아이템을 각각 2회 지급한다. 한 슬롯을 사용하면 `×2 → ×1 → 비어 있음` 순서로 남은 횟수를 HUD에 표시한다.
- 캠페인은 기존 총 2회 회복 기회를 유지한다. Q/R에 응급 수복팩을 한 번씩 지급하며 대전의 슬롯당 2회 규칙을 적용하지 않는다.
- 에너지 드링크는 최대 HP 60% 즉시 회복과 5초 가속을 제공한다. 응급 수복팩은 최대 HP 100%까지 즉시 완전 회복한다.
- Q/R은 1초의 공용 아이템 재사용 대기시간을 가져 두 슬롯을 같은 순간 연속 소비할 수 없다.
- 아이템 사용 시 영웅 중심의 이중 색상 파동, 입자 폭발과 아이템명·실제 회복량 팝업을 함께 표시한다.
- 아이템 상점은 추가하지 않는다. 전투 전 편성 선택과 제한된 2회 사용 판단을 유지해 건설·전술지원 크레딧 경제와 섞이지 않게 한다.
- 종족별 회복 전술지원은 영웅과 현재 진군대 모두를 1초마다 최대 HP 3%씩 8초간 회복한다. 플레이어·동료·적 영웅 모두 같은 팀 규칙을 적용한다.
- 현재 별도 에너지 자원은 없으므로, 회복형 생존기가 없는 영웅도 거점 안전 회복·장착 아이템·팀 회복 전술지원으로 전열을 복구할 수 있게 한다.
