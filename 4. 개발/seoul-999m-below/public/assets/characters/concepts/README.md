## Shared prompt direction

- Original 2D top-down action RPG pixel character sheets.
- Polished late-1990s Korean/Japanese PC action-RPG clarity without copying an existing game or character.
- Large readable sprites, crisp hand-placed pixel clusters, strong silhouette and expressive directional action arcs.
- Dark underground industrial horror with restrained B-movie household-tool humor.
- Each sheet includes a large hero pose, front/back/left/right views and signature movement, attack, drill and skill-effect studies.
- No labels, logos, UI or watermark inside the image.

## Usage status

These are approval and production-reference concept sheets, not animation-ready sprite atlases. After a character design is approved, create a separate fixed-grid sprite atlas with consistent frame dimensions, anchors, directions and animation timing.

## Revised weapon rule

- Human equipment should look improvised, cheap, patched and slightly unreliable rather than premium fantasy or sci-fi gear.
- Character actions and impact effects may remain stylish and exciting. The contrast between shabby equipment and expert combat is intentional.
- Characters should read as deliberately costumed B-movie heroes, not unhoused people. Yoo's football kit and Kang's fake-luxury sewer outfit are key examples.
