# 유승천 게임 스프라이트 v1

설계 원본 묶음은 `3. 설계/케릭터/휴먼/유승천/게임스프라이트/v1/`에 보관한다. 이 디렉터리의 PNG는 게임이 직접 불러오는 런타임 사본이다.

## 런타임 규격

- 모든 시트는 `1536×1024px`, `6열×4행`이다.
- 생성 결과의 프레임 간격은 256px이지만 첫 열의 실제 시작점이 x=64px 밀려 있다. 런타임은 이 오프셋을 보정해 자르고 발 기준점에 맞춰 `52×52` 논리 픽셀로 고품질 축소 표시한다.
- 행 순서: `아래쪽 / 왼쪽 / 오른쪽 / 위쪽`.
- 맵과 타일은 최근접 보간을 유지하지만, 고해상도 생성 스프라이트는 축소 시 깨짐을 막기 위해 고품질 보간을 사용한다. 하얀 체크 배경을 제거한 `-alpha.png` 파일을 런타임에서 사용한다.
- `-alpha`가 없는 원본도 생성 결과 보존용으로 함께 둔다.

## 파일과 프레임

| 파일 | 프레임 1~6 |
|---|---|
| `yoo-locomotion-v1-alpha.png` | 대기 2프레임, 오염 없이 분리된 달리기 2프레임 왕복 |
| `yoo-basic-attack-v1-alpha.png` | 준비, 예비 동작, 베기, 적중, 관성, 회수 |
| `yoo-whirlwind-v1-alpha.png` | 회전 준비부터 한 바퀴 회전·회수 |
| `yoo-thrust-dash-v2-alpha.png` | 낮은 준비, 도약, 장난감검 찌르기, 회수 |
| `yoo-blue-drill-burst-v1-alpha.png` | 드릴 고정, 예열, 균열, 과회전, 파편, 회수 |
| `yoo-hurt-down-v1-alpha.png` | 대기, 피격, 비틀거림, 검 놓침, 낙하, 전투불능 |

부활은 현재 전투불능 프레임을 역순으로 재생한다. 다음 아트 패스에서 드릴을 두드려 다시 켜는 전용 부활 시트로 교체할 수 있다.

생성 시트의 뒤쪽 이동 프레임은 옆 프레임의 픽셀이 경계에 섞여 있어 런타임에서 사용하지 않는다. 이동 시트는 각 프레임의 좌우 16px 안전 여백을 제외하고, 오염 없이 분리된 2개 달리기 프레임을 왕복한다. 일반 액션의 마지막 회수 프레임은 첫 준비 프레임으로 연결한다.

기본 공격·회오리·돌진·드릴 생성 시트는 동작 참고 원본으로 보존하지만 현재 런타임에서는 직접 재생하지 않는다. 큰 검광과 파편이 인접 프레임 영역까지 넘어가 분리할 수 없기 때문이다. 게임에서는 중심이 검증된 이동 본체에 회전·이동·진동·스케일 변형을 적용하고 검광·드릴·참격 효과를 별도 캔버스 레이어로 출력한다.

검 액션의 자세 기준은 `3. 설계/케릭터/휴먼/유승천/액션포즈/v2/human-yoo-seungcheon-sword-action-poses-v2-left-hand.png`이다. 이 시트의 회오리 휘두름, 전방 일직선 찌르기, 머리 위 충전, 내려치기 포즈를 바탕으로 기술 중 본체의 고정 검만 숨기고 왼손 관절에서 같은 청회색 검을 움직인다. 디자인 시트는 동작 참고용이며 런타임 프레임으로 직접 크롭하지 않는다. v1 포즈 시트는 노란 검과 반대 손 배치 오류가 있어 폐기 기준으로만 보존한다.

## 생성 기준

Codex 내장 이미지 생성 도구로 제작했다. 공통 프롬프트에는 다음을 명시했다.

- 유승천 v3 콘셉트의 짙은 피부, 짧은 검은 머리, 무상표 남색·회백색 축구 운동복을 모든 방향과 프레임에서 유지
- 넓고 짧은 청회색 장난감검·붉은 손잡이와 전선은 왼손, 테이프·전선이 드러난 파란 고철 드릴은 오른팔에 방향별로 일관되게 유지
- 기존 게임 캐릭터를 복제하지 않는 독창적인 고전 한국 PC 액션 RPG풍 픽셀 아트
- 정확한 6열×4행, 행별 방향과 동작별 프레임 역할, 투명 배경, 글자·로고·UI 없음
- 장비 외형은 B급으로 허술하게, 동작의 자세·속도감·타격 효과는 강하게 표현

각 시트는 이동, 장난감검 기본 공격, 회오리베기, 돌격 찌르기, 파란 드릴 전개, 피격·전투불능 동작을 별도 프롬프트로 생성했다. 최초 돌격 찌르기 시트는 드릴이 앞서는 오류가 있어 장난감검이 선두 무기가 되도록 v2로 다시 제작했다.

교정 액션 포즈 시트 v2는 원본 청회색 검·붉은 가드와 전선·왼손 그립을 고정하면서 `발을 고정한 회오리 검 궤도`, `검과 진행 방향의 일직선`, `머리 위 청색 충전`, `초승달을 발사하는 내려치기`가 각각 분리되어 읽히도록 생성했다.
