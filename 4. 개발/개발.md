# 개발 작업 공간

실제 게임 프로젝트와 소스 코드는 이 폴더 아래에 둔다.

프로젝트 기술 스택이 확정되면 애플리케이션을 초기화하고 다음 내용을 이 문서에 기록한다.

- 개발 환경 실행 방법
- 테스트 실행 방법
- 프로덕션 빌드 방법
- 주요 디렉터리 구조
- 필수 환경 변수

## 리듬 축구 프로토타입

- 위치: `4. 개발/rhythm-football/`
- 개발 실행: `npm run dev`
- 프로덕션 빌드: `npm run build`
- 테스트: `npm test`
- 핵심 코드: `app/RhythmFootball.tsx`
- 필수 환경 변수: 없음
