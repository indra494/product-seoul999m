# OpenAI Game Builders Seoul 예선 제출·심사 기준

## 문서 상태

- 구분: 공식 외부 정보
- 확인일: 2026-08-25
- 출처: https://openaigame2026.com/
- 적용 대상: Track 1 Online Warm-up Challenge

## 공식 사실

- 온라인 예선에서 본선 진출 40팀을 선정한다.
- Track 1의 방향은 `From zero to one: build with Codex`, 즉 Codex와 함께 아이디어를 플레이 가능한 게임으로 구현하는 것이다.
- Track 1에는 별도의 장르·소재 주제가 명시되어 있지 않다. 현장 공개 주제는 Track 2에 적용된다.
- 심사 항목은 다음 5개다.
  1. Playability: 게임이 실제로 잘 작동하는가?
  2. Originality: 아이디어와 플레이 방식이 독창적인가?
  3. Codex Collaboration: Codex를 효과적으로 활용했는가?
  4. Release Potential: Hive를 통해 서비스를 확장할 수 있는가?
  5. Presentation: 게임과 개발 과정이 명확하게 전달되는가?
- 필수 제출물은 게임 제목, 200자 이내 게임 소개, 브라우저에서 바로 실행되는 공개 플레이 링크, 16:9 권장 JPG 또는 PNG 썸네일이다.
- 플레이 링크는 심사 기간 중 접속 가능하고, 별도 승인이나 제약 없이 접근할 수 있어야 하며, 로그인 필요 시 테스트 계정과 조작·실행 방법을 제공해야 한다.
- 3분 이내 실제 플레이 영상과 Codex 활용 과정 설명은 선택 제출이며 가산점 대상이다.
- Codex 활용 설명은 사용 위치, 구현 기능, 해결한 문제, 사람이 직접 결정한 부분을 구분해 설명하도록 안내한다.
- 기존 프로젝트를 활용할 수 있으나 챌린지 기간에 새롭게 개발한 내용을 명기해야 한다.

## 프로젝트 적용 해석

- `서울 지하 999M`은 브라우저 게임이며 Codex 협업 기록이 충분해 참가 방향과 부합한다.
- 예선 경쟁력은 콘텐츠 양보다 첫 접속 안정성, 첫 30초 내 핵심 재미 전달, 굴착과 진군 지휘의 독창성 증명, 공개 링크와 제출 자료의 완성도에 크게 좌우될 가능성이 높다.
- 이 해석은 공식 심사 점수 배점이나 경쟁작 수준이 공개되지 않은 상태에서의 프로젝트 판단이며 공식 사실과 구분한다.
