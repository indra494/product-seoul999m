# 서울 지하 999M 대전 경제·전술·정예병 설계 v0.1

## 문서 상태

- 확정일: 2026-08-25
- 상태: `구현 기준`
- 기준 기획: `2. 기획/대전-경제-전술-정예병-기획-v0.1.md`

## 1. 모듈 경계

- `game/skirmishEconomy.ts`: 처치·설치물 보상과 컴퓨터 크레딧 배율
- `game/tacticalSupport.ts`: 전술지원 5종 데이터, 공용 재사용, 회복 틱 규칙
- `game/eliteMinions.ts`: 정예병 예약 가격·해금·간격·웨이브 교체 규칙
- `game/minionResearch.ts`: 연구 비용, 구매 해금 웨이브, 자동 최소 성장
- `game/content.ts`: 12종 진군대와 15종 설치물 데이터
- `app/Seoul999mBelow.tsx`: 지갑 차감, 출전 큐, 전술 실행, 지원 시설 효과, AI 소비와 VFX 결선
- `game/onlineRoom.ts`: 신규 정예 역할과 전술·예약 명령 타입

캠페인 전용 출전 큐와 적 경계 행동은 기존 값을 유지한다.

## 2. 런타임 상태

### 팀 전술 상태

```ts
type TacticalTeamState = {
  cooldownUntil: number;
  defenseUntil: number;
  offenseUntil: number;
  recoveryUntil: number;
  recoveryNextAt: number;
};
```

회복 전술 발동 시 그 순간 살아 있는 진군대의 `tacticalRecoveryUntil`을 기록한다. 팀 상태만 검사해 새 출전 병력이 회복 대상에 섞이는 오류를 방지한다.

### 정예병 상태

```ts
type EliteDeploymentState = {
  reserved: boolean;
  lastSpawnWave: number;
};
```

- 예약은 즉시 돈을 차감한다.
- 다음 웨이브 큐를 만들 때 일반 역할 하나를 `elite`로 교체하고 예약을 소비한다.
- 정예병 큐가 만들어진 시점을 출전 웨이브로 기록해 중복 클릭과 재접속 중복 출전을 막는다.

### 상시 지원 시설 상태

- 진군대에 시간제 출전 버프 상태를 저장하지 않는다. 피해·이동·사거리 계산 순간 자기 팀의 살아 있고 건설 완료된 `support` 설치물을 조회한다.
- `supportAura`는 `kind`, 1레벨 수치와 2레벨 수치를 가진다. 휴먼 공격력은 피해 계산, 버그본 이동속도는 진군대 이동 주기, AI 사거리는 사격병·정예병의 공격 위치 계산에 합산한다.
- 시설이 파괴·철거되면 다음 계산부터 효과가 사라지므로 별도 만료 타이머나 유닛 상태 정리가 필요 없다.
- 상시 적용 대상 진군대에는 시설이 살아 있는 동안 종족색 광원과 상태 고리를 표시한다.

### 지역 제어 공격 설치물

- `BuildableDefinition.control`은 `shock | acid | tether`와 제어 시간, 폭발 반경·지대 지속시간·틱 피해를 선택적으로 가진다.
- 휴먼 감전과 AI 구속 투사체는 공용 `Shot.stun`을 사용한다. 정예병의 기존 제어 저항은 투사체 적중 처리에서 유지한다.
- 버그본 포자 투사체는 공용 폭발 처리 뒤 팀과 원본 설치물을 가진 `acid` 필드를 만든다. 필드는 자기 팀이 아닌 유닛만 피해를 주며 설치물 이름으로 피해 출처를 기록한다.
- 신규 투사체 `shock`, `spore`, `tether`는 기존 투사체 배열·온라인 호스트 시뮬레이션·Canvas 렌더 경로를 공유한다.

## 3. 정예 전투 판정

- `MinionRole`에 `elite`를 추가한다.
- 휴먼 정예병은 사거리 안에서 `splash` 투사체를 발사한다.
- 버그본 정예병은 기본 근접 유효 프레임에 반경 1.3칸의 적 최대 3명을 타격한다.
- AI 정예병은 `pierce` 투사체를 발사한다.
- 정예병은 공용 길찾기와 포위 슬롯을 사용하되 자신의 실제 사거리를 공격 위치 선정에 전달한다.
- 정예병의 코어 본체 피해 배율은 일반 호위병보다 높고 파쇄병보다 낮은 1.35배다.

## 4. 출전 상한

- 일반 큐는 팀당 살아 있는 진군대가 12명 이상이면 출전하지 않는다.
- 긴급 증원 큐만 17명까지 출전 가능하다.
- 일반 큐가 5초 이상 막히면 기존 정책대로 취소한다.
- 정예 예약은 일반 웨이브 한 자리를 대체하므로 별도 상한을 늘리지 않는다.

## 5. 온라인 동기화

- 전술 역할 타입에 `recovery`, `reinforce`를 추가한다.
- 정예 예약 명령 `elite`를 추가한다.
- 호스트 스냅샷의 `minionRole`은 `elite`를 허용한다.
- 로컬 입력은 즉시 예측하고 WebSocket 명령을 전송한다. 호스트는 같은 팀 지갑·예약 조건을 다시 검증한다.
- 출전된 정예병과 증원 병력은 기존 미니언 스냅샷으로 동기화한다.

## 6. 시각 규격

### 정예병

- 기존 진군대보다 화면 표시 크기 1.28배
- 발밑 이중 팀색 원과 `정예` 배지
- 이동은 단일 투명 런타임 이미지를 미세 상하 이동·회전해 표현하고, 공격은 종족별 반동·돌진·예고 VFX를 결합한다.
- 생성 원본은 `3. 설계/진군대/<종족>/v3/`, 런타임 사본은 `public/assets/minions/<종족>/elite/`에 보관한다.

### 지원 시설

- 코어 주변 한 타일에서 읽히는 낮은 3/4 탑다운 실루엣
- 공격 포신 대신 상자·페로몬 촉수·중계 안테나로 기능을 구별한다.
- 시설 생존 중 적용 대상 진군대 발밑에 종족색 상시 고리를 표시하고, 출전 순간에는 짧은 신호선을 추가 표시한다.
- 생성 원본은 `3. 설계/설치물/<종족>/v3/`, 런타임 사본은 종족별 `public/assets/buildables/`에 보관한다.

### 지역 제어 공격 시설

- 휴먼은 낮고 넓은 폐배터리·구리 코일과 청록 감전 아크, 버그본은 갑각·균사·산성 낭과 녹색 누출, AI는 비대칭 이중 전극과 적색 센서·청록 구속 아크를 사용한다.
- 한 타일 중앙 접점, 3/4 탑다운, 투명 배경의 512×512 런타임 PNG로 통일한다.
- 생성 원본은 `3. 설계/설치물/<종족>/v4/게임에셋/`, 런타임 사본은 종족별 `public/assets/buildables/`에 보관한다.
