# 서울 지하 999M 프로토타입 기술 설계

- React는 캐릭터 선택, 거점 선택, HUD와 승패·재시작 상태를 관리한다.
- Canvas 2D는 56×36 지하 타일 맵, 카메라, 굴착·매립, 캐릭터, 투사체, 숨은 지뢰, 아이템, 시야와 전투 효과를 60FPS 목표로 처리한다.
- 캐릭터는 데이터 객체로 이동속도, 체력, 기본공격 사거리·피해, 특수기술 대기시간과 색상을 가진다.
- 활성 캐릭터는 포인터 목적지 명령을 기본으로 따르고 WASD·방향키를 보조 입력으로 사용한다.
- AI 팀은 거점 방어와 플레이어 거점 공격 상태를 일정 시간마다 전환한다.
- 각 흙 타일은 종류, 현재·최대 내구도, 열린 땅굴 여부, 숨은 아이템과 지뢰 정보를 가진다.
- 캐릭터는 열린 타일로만 이동하며 닫힌 타일 방향 입력은 일정 주기로 굴착 피해를 준다.
- 남은 내구도 비율에 따라 금 1단계, 2단계와 붕괴 직전 균열을 도트 선으로 그린다.
- 매립은 비어 있는 인접 땅굴을 내구도 2의 흙으로 되돌리고, 지뢰 설치는 해당 흙에 소유자와 폭발 피해를 기록한다.
- 타일이 파괴될 때 숨은 아이템을 열린 칸의 픽업으로 바꾸며 접근한 캐릭터의 드릴 피해, 체력 또는 폭탄 수를 강화한다.
- 거점은 양 진영별 후보 좌표 배열에서 무작위로 하나씩 선택하고 주변을 열린 시작 방으로 만든다.
- 휴먼 거점은 `3. 설계/거점/휴먼/서울/v1/`의 채택 디자인에서 메인 건물만 분리한 투명 PNG를 약 3×2타일(118×78 논리 픽셀) 크기로 렌더링한다. 원본 PNG 해상도는 유지하고 게임 표시 크기만 첫 적용의 2/3로 줄인다. 논리 공격·충돌 중심은 기존 거점 좌표 한 칸을 유지하고, 아군·적군은 바닥 표식·체력 바와 적군 색상 필터로 구분한다. 이미지 로딩 실패 시 기존 절차적 거점 도형을 폴백으로 사용한다.
- 고정 포탑은 건물 뒤 중앙이 아니라 좌우 외곽 패드에 배치하고, 자동 굴착대는 거점 이미지의 전면 터널 문 아래 열린 칸에서 출전한다. 건물·포탑·유닛은 발 위치의 월드 Y값으로 정렬해 지붕 위를 걷거나 뒤쪽 유닛의 몸만 노출되지 않게 한다.
- 월드는 2240×1440 크기의 56×36 타일로 유지하고, 논리 캔버스는 1120×720으로 설정해 약 28×18칸만 확대 렌더링한다.
- 논리 캔버스는 브라우저 전체 플레이 영역으로 확대하며, 카메라는 활성 캐릭터를 따라 월드 경계 안에서 이동한다.
- 시야는 타일별 `탐색 여부`와 현재 아군 거리로 계산한다. 미탐색 타일은 완전 검정, 탐색 타일은 반투명 회색 마스크 아래 기억된 지형만, 현재 시야는 모든 개체를 그린다.
- 안개는 타일마다 사각 덮개를 반복하지 않고 별도의 오프스크린 마스크에 합성한다. 탐색 경계에는 블러를, 현재 시야에는 방사형 그라디언트를 사용한다.
- 화살은 픽셀 단위 투사체로 열린 땅굴을 진행하며 상대 캐릭터에게 피해를 주고 흙 타일과 충돌하면 사라진다.
- 굴삭기 휘두르기는 별도 입력으로 인접 흙 또는 상대를 공격한다. 이동 굴착은 흙에만 피해를 주고 캐릭터에게 피해를 주지 않는다.
- 프로토타입은 클라이언트 메모리에서만 실행하며 서버·저장 기능을 사용하지 않는다.

## 2026-08-20 단일 캐릭터·자동 진군 확장 설계

- 플레이어 영웅 한 명과 AI 적 영웅 한 명을 별도 역할로 관리하고, 자동 유닛은 `minion` 역할의 경량 데이터로 관리한다.

- 포인터 좌표를 캔버스 논리 좌표와 월드 좌표로 변환해 마우스와 터치 입력이 동일한 이동·공격·조준 로직을 사용한다.
- 포인터 목적지는 타일 경로가 아니라 캐릭터의 연속 월드 좌표에서 실제 클릭 월드 좌표로 향하는 정규화 벡터로 계산한다.
- 영웅 위치는 프레임 시간 기반 연속 좌표로 갱신하고, 매 프레임 몸 반지름의 네 모서리가 모두 열린 바닥인지 검사한다. 논리 점유 칸은 현재 연속 좌표가 포함된 타일로만 동기화한다.
- 이동 벡터 앞쪽과 양옆의 충돌 탐침이 처음 만난 파괴 가능한 흙 한 칸에 굴착 피해를 준다. 기반암·거점·포탑·다른 유닛은 이동을 막으며, 열린 공간에서는 타일 중심이나 8방향 중간점을 경유하지 않는다.
- 정규화된 대각선 이동이 막히면 먼저 캐릭터 중심 진행선을 인접 타일까지 탐색한다. 중심선이 파괴 가능 흙에 닿으면 그 타일을 굴착하고, 중심선은 열려 있으나 몸 모서리만 걸린 경우에만 같은 프레임의 X축·Y축 후보 중 통과 가능한 축으로 미끄러진다. 두 축도 모두 막히면 몸 전방 충돌 타일을 탐색해 굴착한다.
- 영웅 스프라이트 방향은 실제 월드 좌표 변화 벡터로 갱신한다. 4방향 행 선택에서 대각선의 두 성분이 같으면 상·하 행을 선택한다.
- 적 타일을 목적지로 지정하면 인접한 도달 가능 타일까지 경로를 계산하고, 사거리 안에서는 이동보다 기본 공격을 우선한다.
- 캔버스의 `Ctrl + 좌클릭`은 목적지 명령을 만들지 않고 현재 위치에서 포인터 방향의 8방향 근접 기본 공격을 즉시 요청한다.
- 방향이 없는 기술 1·3은 키다운 또는 버튼 탭에 즉시 실행한다. 방향 기술 2·4는 키·버튼을 누르는 동안 조준 상태로 유지하고 키업·포인터업에 현재 커서 방향으로 실행한다.
- 조준 가이드는 캐릭터 중심에서 커서로 향하는 정규화된 360도 방향선과 최대 사거리 끝점을 표시한다. 돌격 찌르기는 막히는 첫 벽을 표시하고, 필살기 참격은 지형을 관통하므로 최대 사거리 전체를 표시한다.
- 이동·일반 굴착은 8방향을 처리한다. 대각선으로 맞닿은 파괴 가능한 흙은 해당 한 타일에 굴착 피해를 주되, 실제 대각선 진입은 양옆 직교 칸이 모두 열린 뒤에만 허용한다. 기반암·거점·포탑은 통과하지 않는다.
- 직선 기술 판정은 타일 열거가 아니라 월드 좌표 선분과 대상 원형 히트박스의 교차로 계산한다. 참격은 시전 시 대상을 미리 확정하지 않고, 충전 뒤 전진하는 파동의 이전·현재 프레임 선분과 현재 대상 히트박스를 비교해 처음 접촉한 대상에게만 피해를 준다.
- 플레이어 영웅의 충돌 중심은 논리 타일 중심이 아니라 화면 렌더링과 동일한 연속 월드 좌표를 사용한다. 총알도 이전·현재 위치 구간과 대상 원형 히트박스를 검사하므로 충돌 전에 이동한 영웅은 피해를 피할 수 있다.
- 카메라는 `follow`와 `free` 두 상태를 가진다. 기본은 영웅을 감쇠 추적하고, 우클릭 드래그 또는 미니맵 클릭 시 `free`로 전환해 월드 경계 안에서 이동한다. `Space` 입력은 즉시 `follow`로 복귀한다.
- 미니맵은 메인 캔버스 우측 하단 오버레이로 그린다. `seen`과 `memory`로 지형을 표시하고 적 유닛·적 거점·적 포탑은 현재 `visible`일 때만 표시한다. 미니맵 포인터 좌표는 월드 좌표로 역변환해 카메라 중심을 갱신하며 캐릭터 이동 명령은 만들지 않는다.
- 근접 공격은 공격자, 방향, 피해와 남은 준비 시간을 가진 예약 판정으로 저장한다. 준비 시간이 끝난 프레임에 공격자 현재 위치를 기준으로 부채꼴 범위를 다시 검사하고, 이미 벗어난 대상에는 피해를 주지 않는다.
- 자동 유닛은 열린 타일만 대상으로 BFS 최단 경로를 계산한다. 인접 적이 있으면 경로 이동보다 공격을 우선한다.
- 아군과 적군 일반 유닛은 일정 주기로 거점에서 생성하고 최대 수를 제한한다.
- 자동 유닛은 경로상의 다른 아군에게 막힌 시간을 누적한다. 파쇄병이 1초 이상 막히고 반경 2칸 안에 같은 팀 진군대가 3명 이상이면 진행축의 좌·우 후보 중 기반암·거점·설치물이 없는 쪽의 현재 옆칸과 전방 옆칸을 파괴해 2칸 교전면을 만든다. 사용 뒤 5초 동안 다시 발동하지 않는다.
- 목표까지 열린 BFS 경로가 5초 동안 존재하지 않는 자동 유닛은 전투불능 상태로 전환해 회수한다. 단순 점유 충돌은 경로 부재 시간에 포함하지 않는다.

- 적 영웅 AI는 `후퇴`, `거점 방어`, `원거리 교전`, `근접 교전`, `굴착 공격` 우선순위를 매 판단 주기마다 평가한다.
- 포탑은 위치, 팀, 체력, 사거리, 재사용 대기시간과 건설 여부를 가지며 시야가 열린 적 유닛을 자동 조준한다.
- 크레딧은 누적 시간, 타일 속 광석 보상과 적 처치 보상으로 갱신하며 HUD에 표시한다.
