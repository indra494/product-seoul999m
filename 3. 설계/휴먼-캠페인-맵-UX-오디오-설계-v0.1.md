### 3장 전투 개시 상태

- 시작 좌표는 중앙 2×2 영역을 둘러싼 유승천·김씨·안서나·강인함의 밀집 배치다.
- 최초 5.2초 동안 플레이어와 상대 AI를 잠그고 대사를 보여 준다.
- 대치 종료와 동시에 유승천의 이동·기본 공격·기술 입력을 해제하고, 김씨·안서나·강인함의 자유 난투 AI를 활성화한다.
- AI는 최근 자신을 공격한 상대에게 반격하고, 체력이 매우 낮은 상대를 마무리하며, 이미 여러 명이 노리는 대상에는 낮은 우선순위를 준다. 일반 표적은 2.2~4초마다 다시 평가한다.
- 세 동료 AI가 표적을 새로 평가할 때 플레이어 유승천을 선택하는 비율은 70%, 다른 동료를 선택하는 비율은 30%로 둔다. 각 비율 그룹 안에서는 거리·최근 공격자·낮은 체력·집중 공격 여부를 비교한다.
- 안서나는 4칸 거리를 유지하고 체력 72% 미만에서 치료를 우선한다. 김씨는 근접 추격과 주변 2명 이상일 때 전기장을 우선한다. 강인함은 저체력에서 방어 강화, 중거리에서 뚜껑 투척, 근거리에서 밀치기를 우선한다.
- 3장 참가자 체력은 350~480으로 높이고 참가자끼리 주고받는 피해를 기본값의 62%로 줄여 대련 시간이 충분히 이어지게 한다.
- 체력 0은 사망이 아니라 기권·대련 이탈이며, 승리 뒤 네 사람의 관계가 더 단단해진다.

### 3장 이동·공격 시각 동기화

- 근접 판정은 4방향 타일 이동에서 대각선으로 맞닿은 상대도 교전할 수 있도록 체비쇼프 거리로 계산하고, 추격·거리 유지 판단은 실제 직선 거리를 사용한다.
- AI의 논리 타일은 즉시 갱신하되 화면 좌표는 약 0.3초간 부드럽게 보간한다. 밀치기에도 같은 보간을 적용해 순간이동처럼 보이지 않게 한다.
- 3장 동료의 몸체는 방향이 검증된 대기·이동 시트만 사용하고, 공격은 짧은 전진 동작과 별도의 방향성 효과로 표시한다. 서로 다른 크기의 기술 원본 셀을 몸체 프레임으로 직접 축소하지 않는다.
- 휴먼 로스터의 김씨·안서나·강인함 원본 측면 시트는 모두 오른쪽을 향한다. 좌우 반전은 이 원본 방향과 현재 공격 방향을 비교해 한 번만 적용한다. 분사·방패·전자레인지 계열 효과는 시전자에서 표적 쪽을 향하고, 회복·강화 효과만 시전자 중심의 대칭 효과를 사용한다.

## 2장 호송 상태 모델

- `ScientistUnit` 3명을 일반 전투 유닛과 분리한다: `escortPointIndex`, `hp`, `alive`, `destinationProgress`.
- 박사는 유승천 위치와 무관하게 사전에 정의한 협곡 경유점 배열을 순서대로 이동한다. 길이 막히면 같은 폭 안에서 우회하며, 경유점 1칸 이내에 진입하면 다음 지점으로 진행한다.
- 박사 중 한 명이라도 사망하면 즉시 패배하고, 세 명 모두가 평택 입구 반경에 진입해야 승리한다.
- 절벽 설치물은 굴착·이동 불가 고지 타일 위에 고정 배치하고 아래 협곡 통로의 박사를 우선 조준한다. 고지는 통로와 분리되어 적 지상 유닛이 내려오지 않으며, 플레이어는 원거리 기술로 포대를 제거하거나 몸으로 투사체를 끊어 호송대를 보호한다.
- 우측 종착 구조물은 적 코어가 아니라 휴먼 `평택거점(연구소)`로 표시한다. 박사가 입구 반경에 진입하면 생존 인원을 판정한다.

## 1장 정찰충 도입 상태 모델

- `campaignScout` 유닛을 서울 거점 전방 5칸에 배치한다.
- 0~1.4초는 거점을 바라보며 정지하고, 1.4~3.2초는 반대 방향으로 달아난 뒤 전장에서 제거한다.
- 정찰충이 도망가는 동안 유승천 대사와 1차 침입은 시작하지 않는다. 정찰 종료 뒤 두 대사를 순서대로 출력하고 약 8.5초 시점에 1차 침입을 시작한다.

## 가독성 규격

- 웹 UI 기본 글꼴: `system-ui, "Noto Sans KR", "Malgun Gothic", sans-serif`.
- 픽셀 표현은 Canvas의 캐릭터·지형에만 남기고 HUD, 메뉴, 버튼, 대사와 미션 설명에는 사용하지 않는다.
- 기본 본문 최소 12px, 조작/보조문구 최소 11px, HUD 핵심 수치·미션 목표 최소 14px.
- 어두운 패널 위 일반 글자는 명도 대비가 높은 `#f2eee3`, 보조문구는 `#c9c4b8` 이상을 사용한다. 7~8px 글자와 저대비 회색을 제거한다.

## 배경음 구현 규격

- 외부 저작권 음원을 임의로 포함하지 않는다. 제출판은 브라우저 `AudioContext`로 생성하는 반복 앰비언트 레이어 또는 사용 승인된 오디오 에셋만 사용한다.
- 첫 사용자 입력 뒤 오디오를 시작한다. 브라우저 자동재생 제한을 준수한다.
- 공통 베이스: 낮은 드론 + 느린 금속성 펄스. 전투 중에는 타악/노이즈 레이어를 추가하며, 결과·일시정지 시 볼륨을 낮춘다.
- 장별 테마는 주파수·리듬 패턴만 바꿔 에셋 수를 과도하게 늘리지 않는다. 2장에는 행진 펄스, 3장에는 불협화음, 4장에는 군체성 리듬, 5장에는 붕괴 경고음을 사용한다.
