# 캠페인 모드 분리 설계 v0.1

## 상태

- 분류: 확정 구현
- 기준 기획: `2. 기획/휴먼-캠페인-챕터1-기획-v0.1.md`

## 화면 상태

최초에는 `첫 화면 → 공통 프롤로그 → 장 선택 → 작전 상세 → 미시청 장별 시네마틱 → 전투`, 공통 프롤로그를 본 뒤에는 `첫 화면 → 장 선택` 흐름을 사용한다. 로스터 선택 화면은 `컴퓨터와 대전`에서만 사용한다.

### 공통 프롤로그

- 배포 파일은 화면에 한국어 원문이 포함된 `public/assets/opening/seoul-999m-opening-v12.mp4`만 사용한다. 별도 자막 트랙은 추가하지 않는다.
- 시청 여부는 `seoul999m.prologueSeen`에 `1`로 저장한다. 영상 종료와 `SKIP` 모두 값을 기록하고 `chapters`로 이동한다.
- 작전지도의 `프롤로그 다시 보기`는 저장값과 관계없이 `prologue`로 이동한다. 다시 보기 종료·건너뛰기도 작전지도로 복귀하며, 장별 시네마틱의 시청 목록에는 영향을 주지 않는다.

### 진행 저장과 잠금

- 완료 장 목록은 `seoul999m.campaign.completed.v1`에 JSON 배열로 저장한다. 제1장은 항상 열고, 연속으로 완료된 마지막 장의 다음 장 하나까지만 선택 가능하게 한다.
- 지도 노드는 `completed / available / locked` 세 상태를 사용한다. 완료 장은 재입장 가능하고, 잠금 장 버튼은 실제 `disabled` 속성과 접근성 이름의 `LOCK`을 함께 사용한다.
- 성공 결과가 확정된 프레임 뒤 현재 장을 완료 목록에 기록한다. 패배·중도 이탈·시네마틱 시청만으로는 다음 장을 열지 않는다.

### 장별 시네마틱

- 배포 파일은 `public/assets/campaign/cinematics/human_story_01.mp4`부터 `human_story_05.mp4`까지 둔다.
- 시청 목록은 `seoul999m.campaign.cinematicsSeen.v1`에 저장한다. 미시청 장의 `작전 시작`만 `cinematic` 상태를 거치며 종료·건너뛰기 후 전투 에셋을 준비해 `play`로 이동한다.
- 상세의 다시 보기는 같은 영상을 재생하되 종료·건너뛰기 후 `briefing`으로 돌아간다. 영상 로드 실패 시에도 건너뛰어 작전을 시작할 수 있다.
- 공통 프롤로그와 장별 시네마틱 동안 메뉴 BGM을 정지해 영상 음성과 겹치지 않게 한다. 작전 상세는 동영상 배경 대신 작전지도와 같은 `MenuSceneBackdrop`을 사용한다.

## 전투 설정

- `skirmish`: 현재의 양 진영 거점전, 14초 4인 웨이브, A/B 전략 지시를 유지한다.
- `campaign1`: 휴먼 유승천 고정, 아군 3명은 초기 배치 후 보충하지 않는다. 1차 침입 24마리를 모두 정리하면 2차 강화 침입 32마리를 대기열에 넣는다. 동시 적 상한은 기존 12명을 유지하되, 두 번째 침입의 일반 개체에는 HP ×1.75·피해 ×1.7·방어 +5·속도 ×1.12를 적용한다.
- 1차에는 6마리마다 침투충, 10마리마다 군체 선두를 섞고, 2차에는 4마리마다 침투충, 7마리마다 군체 선두를 섞는다.
- 침투충은 일반 적 우선순위를 건너뛰고 코어까지 길찾기·공격한다. 일반 적보다 빠르고 코어 피해가 높아 주인공의 직접 저지가 필요하다. 군체 선두는 높은 체력·방어력으로 일반 적의 교전 시간을 늘린다.
- 캠페인 시작 0~2.3초에는 `저게 머지?`, 2.3~5.9초에는 `절대 서울 안으로 들여보내서는 안 돼!`를 유승천 머리 위 Canvas 말풍선으로 렌더링한다.
- 자동 진군대는 모든 행동 틱에서 살아 있는 적 유닛을 설치물·거점보다 먼저 선택한다. 공격 사거리 밖이면 적에게 길찾기 이동한 뒤 교전한다.
- 캠페인 승리는 2차 침입의 적 대기열과 생존 적이 모두 0일 때 판정한다. 코어 파괴 승리 규칙은 캠페인에 사용하지 않는다. 휴먼 코어 파괴 또는 유승천 사망은 즉시 패배이며 유승천의 일반 부활 타이머는 캠페인에서 사용하지 않는다.

## A/B 노선 보완

- `Ctrl+1`과 `Ctrl+2`가 선택한 전략 지점은 각각 A/B 노선의 집결지다.
- 각 노선에는 적 거점 부근의 서로 다른 진입 관문이 자동으로 마지막 경유점으로 붙는다. A는 상단, B는 하단을 우선한다.
- 집결지가 적 거점 근처여도 두 노선은 관문을 통과한 뒤 거점을 향하므로 같은 최단 진입로로 합쳐지지 않는다.
- 관문까지 열린 경로가 없으면 해당 노선은 단절 상태가 되어 기존 후퇴·회수 규칙을 적용한다.
