# 전투 객체 공용 런타임 설계 v0.1

## 목적

- PvC, 캠페인, 이후 네트워크 전장에서 같은 캐릭터·진군대·설치물이 같은 수치와 행동을 사용한다.
- 맵과 시나리오는 객체를 다시 구현하지 않고 `콘텐츠 ID + 팀 + 생성 위치 + 제어 방식`만 지정한다.
- 좌우 방향, 프레임 크롭, 기술 포즈와 이펙트 수정은 한 공용 경로에서 모든 모드에 반영한다.

## 기준 모듈

| 책임 | 기준 파일 | 규칙 |
|---|---|---|
| 영웅·진군대·설치물 원본 데이터 | `game/content.ts` | 이름, 종족, 기본 능력치와 에셋 ID의 단일 기준 |
| 영웅 기술 세트 | `game/heroKits.ts` | 기본 공격과 4개 기술의 모드·수치·VFX 기준 |
| 전투 행동 조회 | `game/heroActions.ts` | 모든 게임 모드가 같은 슬롯의 모드·피해·범위·재사용 시간을 조회 |
| 런타임 객체 생성 | `game/runtimeEntities.ts` | 영웅·진군대·민간인·설치물 생성 팩토리와 공용 런타임 타입 |
| 영웅 화면 표현 | `game/heroPresentation.ts` | 시트·행·프레임·좌우 반전의 단일 계산 기준 |
| 전투 실행·Canvas 표시 | `app/Seoul999mBelow.tsx` | 공용 객체와 행동 규격을 소비하며 캠페인별 별도 영웅 렌더러를 만들지 않음 |

## 맵과 캠페인의 허용 범위

캠페인은 생성 위치와 팀, 플레이어·아레나 AI·동행 AI 같은 제어 방식, 미션용 최종 능력치 보정, 호송·시간 제한·도착 지점·승패 조건만 덧붙일 수 있다.

캠페인이 캐릭터 기술 수치, 스프라이트 프레임 계산, 좌우 반전 또는 기술 이펙트를 다시 구현해서는 안 된다. 캠페인 보정은 공용 행동 결과에 최종 배율로만 적용한다.

## 현재 공용화 상태

- 영웅은 `createHeroUnit`, 진군대는 `createMinionUnit`, 박사는 `createCivilianUnit`, 설치물은 `createBuildableUnit`으로만 생성한다.
- PvC와 캠페인 영웅은 `drawSharedRosterHero` 한 경로에서 같은 `heroFramePlan`과 기술 이펙트를 사용한다.
- 기술 실행 정보는 `heroAction`으로 조회하며 제3장 AI도 같은 기술 모드와 기본 수치를 사용한다.
- 기술 시트는 기술 프레임마다 원본이 바라보는 방향이 다를 수 있으므로 `heroPresentation.ts`의 프레임별 원본 방향표로 반전을 결정한다.
- 유승천 외 11명은 좌우 기술 시트와 별개로 `roster-v4`의 10열 세로 전투 시트를 사용한다. 열은 `기본 공격·1번·2번·필살기·3번`의 정면/후면 쌍이며, 위·아래 공격에서 걷기 프레임을 변형해 대신하지 않는다.
- 안서나의 측면 대기·이동은 원본이 실제 바라보는 왼쪽을 단일 기준으로 유지한다. 강력한 기본 공격은 원본 셀 경계를 침범한 프레임 대신 온전한 프레임을 사용한다.
- 한 프레임은 중간 캔버스에 격리한 뒤 표시해 옆 셀 캐릭터가 섞이지 않게 한다.

## 후속 분리 경계

현재 메인 컴포넌트 안의 프레임 업데이트 루프는 공용 팩토리와 행동 규격을 사용한다. 다음 구조 정리 단계에서는 진군대 AI, 설치물 표적 선택, 투사체 판정을 각각 순수 시스템 모듈로 옮기되 게임 규칙은 바꾸지 않는다.

## 2026-08-25 공용 코어 공성·특성 성장 보정

- `game/coreCombatRules.ts`는 영웅·진군대의 코어 및 방어막 공격 권한을 단일 기준으로 제공한다. 설치물은 계속 코어를 직접 공격하지 않는다.
- 명시적 코어 공격은 일반 근접 타격의 `유닛 → 설치물 → 코어` 충돌 우선순위를 사용하지 않는다. `coreSiege` 판정으로 코어를 먼저 확인해 주변 설치물이 남아 있어도 지정 공격이 코어에 들어가게 한다.
- `stepBattleHero`는 비캠페인 AI 영웅의 최종 전략 목표를 상대 코어로 두고, 코어 사거리 진입 시 공용 `coreSiege` 기본 공격을 사용한다. 제4장 동행 영웅은 코어가 시야에 들어온 경우에만 같은 분기를 사용한다.
- `stepMinion`은 비캠페인 무지시 상태에서도 상대 코어를 최종 목표로 사용하고, 인접 코어 공격에는 같은 공성 우선순위를 적용한다. 캠페인 경계병은 제외한다.
- `game/content.ts`의 영웅 성장표는 LV.1~9 누적 경험치와 능력치 배율을 제공한다. `game/heroTalents.ts`는 LV.3·6·9 단계만 노출하고 기존의 12명별 실제 공격 수·피해·범위·장판·재사용 효과를 그대로 합산한다.
- AI 로봇 `좌표 소거 포격`은 1.6초 수축 조준 뒤 수직 광주, 좌표 격자, 충격 사각 파편과 잔광을 표시한다. 피해 판정 뒤 약 0.5초 동안 후폭풍 이벤트를 보존해 한 프레임 입자만 보이고 사라지는 문제를 막는다.

## 2026-08-25 캠페인 동행 전투원 지역 교전 보정

- 동행 영웅과 캠페인 추종 진군대는 플레이어 추종 분기로 돌아가기 전에 공용 지역 표적 탐색을 수행한다. 우선순위는 적 전투원, 적 설치물, 발견한 적 코어다.
- 지역 표적 판정은 맨해튼 직선거리가 아니라 실제 경로 길이와 `combatApproachPlan`이 계산한 비어 있는 공격 위치를 사용한다. 기본 지역 교전 한계는 24경로 칸이다.
- 동행 영웅의 설치물 자발 공격은 `assistReason: local-threat`로 공용 전투 AI에 전달한다. 코어는 지역 발견 상태를 공용 `coreAssault` 분기에 포함한다.
- 진군대는 지역 코어를 공격할 때 인접 직교 칸만 요구하지 않는다. 자기 기본 사거리와 대각선 위치를 포함한 자유 공격 위치에서 `coreSiege`를 사용한다.
- 경로 복구 시스템이 강제 재합류 상태를 명시한 경우에는 지역 교전 진입을 막아, 전투와 재합류가 서로 목표를 반복해서 덮어쓰지 않게 한다.
