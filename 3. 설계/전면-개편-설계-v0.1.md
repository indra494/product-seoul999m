# 전면 개편 설계 v0.1

## 기준

- 기획: `2. 기획/전면-개편-v0.1.md`
- 공용 전투 데이터는 `content.ts`, `heroKits.ts`, `heroPresentation.ts`, `runtimeEntities.ts`를 계속 사용한다.

## 모듈 변경

### 표현

- `heroPresentation.ts`의 대기 측면 기준과 기술 프레임 기준을 분리한다. 안서나 대기는 고정하고 기술 슬롯 1·2·4만 실측 방향값을 사용한다.
- 강인함은 프레임별 안전 크롭과 더 큰 격리 캔버스를 사용한다.
- `Unit`에 짧은 월드 표식 상태를 추가하고 모든 필살 실행기가 `ultimate` 표식을 생성한다.

### 전투 입력

- 근접 클릭 명령은 `targetId + desiredRange + leash`를 가진다. 갱신 루프는 목표의 현재 좌표로 길을 다시 계산하고 `desiredRange` 안에서만 공격한다.
- 메우기는 `aimFill → releaseFill`의 단발 행동으로 바꾸고 성공·실패 후 즉시 조준을 종료한다.
- 출전 장비는 `MatchConfig.loadout`의 슬롯 2개로 전달하고 경기 중 구매 UI와 크레딧 차감을 제거한다. 캠페인 런타임은 선택값 대신 `[medKit, armorPlate]`를 주입한다.

### 오디오

- 첫 pointer/key 입력에서 하나의 `CombatAudio.unlock()`을 호출한다.
- 메뉴용 `startMenu()`와 맵용 `start(mapId)`를 분리하고 음소거 상태를 UI에 노출한다.
- AudioContext 상태가 suspended면 매 사용자 입력에서 재개를 재시도한다.

### 화면

- `hasSeenPrologue`는 localStorage 키 `seoul999m-prologue-v12-seen`으로 저장한다.
- 프롤로그는 비디오와 skip 버튼만 렌더한다.
- 메뉴 배경은 v12의 1~7 장면 이미지 경로를 CSS cross-fade 레이어로 재사용한다.
- 영웅 상세 패널은 `HeroDefinition + HeroKit`에서 직접 생성해 설명 중복을 막는다.
- 결과 상태는 `announcing → choices` 2단계로 구성한다.
- 공용 AI 영웅 기술은 `PendingBattleHeroImpact` 큐에 공격자·대상·기술·타격 지연을 저장한다. 시전 즉시 모션/VFX/쿨다운을 시작하고 일반기 약 0.39초, 필살기 약 0.62초 뒤 살아 있는 대상의 현재 위치를 다시 검사해 피해를 적용한다.
- `Unit.aiComboLockUntil`은 일반기 애니메이션 종료 뒤 0.7초, 필살기 종료 뒤 1.2초까지 다른 기술 선택을 차단하되 기본 공격과 이동은 허용한다.
- `damagePopups`는 피격 대상 종류와 관계없이 월드 좌표, 팀, 피해량, 치명타 여부를 받는 공용 큐다. `hurt`, `hurtTurret`, `damageBase`만 큐를 생성해 중복 표기를 막는다. 방어막은 `방어막 -N`, 본체는 `-N`, 치명타는 `치명타 -N`으로 렌더한다.
- 플레이어에게 적용된 최근 피해 3건은 로컬 전투 기록으로 유지한다. 캠페인 영웅 사망 시 결과 표시를 3000ms 지연하고 React 결과 상태에 마지막 공격자·기술·피해량·최근 기록을 한 번만 전달한다.
- HUD는 `battle-stage + combat-command-dock` 2행 구조로 나누고 모든 전투 명령 DOM을 dock 안에 둔다. 980px 이하에서는 dock을 가로 스크롤 가능한 단일 조작 열로 바꾼다.
- 데스크톱 dock은 한 행의 `status/build/routes/utility/skills` grid로 구성한다. utility/skills 버튼은 공용 SVG 아이콘 컴포넌트와 `data-tooltip`을 사용하고 키·쿨다운만 상시 노출한다. 툴팁은 hover와 `:focus-visible` 모두 지원한다.
- 크레딧 데이터의 단일 표시 소유자는 status이며 build toggle은 선택한 건설 종류만 표시한다.
- 데스크톱 dock은 좌측 정렬하고 routes 내부를 A/B 2열로 배치한다. status는 고정 64px 안에서 34px 초상, 이름, HP, XP와 별도 자원 요약이 모두 들어가도록 명시적 행 높이를 사용한다.
- 미니맵 접힘 상태는 React state와 effect 내부 ref를 함께 사용한다. ref가 참이면 canvas 미니맵·미니맵 노선 렌더·hit 영역 입력을 모두 건너뛰고, 별도 DOM toggle은 항상 접근 가능하게 유지한다.
- 1120px 이상 dock grid 열은 `hero 200 / build 52 / routes 236 / utility 194 / skills 194`를 기준으로 총 폭을 제한한다. 이 구간에서는 `overflow: visible`을 사용해 build menu와 command tooltip이 잘리지 않게 한다.
- hero card 안에 XP, 크레딧, 아군/적/탐사 요약을 병합하고 기존 별도 자원 카드는 렌더하지 않는다.
- route container는 2행 1열이며 각 행을 `56px key + 3개 동일폭 stance button`으로 구성한다. command button은 44×56px, SVG는 32px, state는 하단 `left:50% + translateX(-50%)`로 중앙 정렬한다.
- 편성 패널은 viewport inset 기반 고정 영역과 독립 스크롤을 사용하고 시작 버튼은 sticky footer로 유지한다.

### 랜덤 거점과 탐색

- `BattleMapDefinition.spawnPairs`에 최소 3개의 180도 대칭 후보쌍을 둔다.
- `resolveBattleSpawns(mapId, seed)`가 후보쌍과 팀 방향을 결정한다. 같은 seed는 같은 결과를 반환한다.
- 맵 생성기는 선택된 거점 주변만 9×9로 열고 나머지는 맵 고유 통로를 후보 거점에 맞춰 연결한다.
- 적 AI 상태에 `knownEnemyCore`, `searchTarget`, `lastEnemyEvidence`를 둔다. 미발견 시 frontier 탐색, 적/시설 조우 시 증거 갱신, 적 코어 시야 진입 시 확정한다.
- 렌더/HUD/미니맵은 미발견 적 거점을 표시하지 않는다. 제5장 천안 목표는 캠페인 예외로 항상 표시한다.

### 캠페인

- 제4장: 벽 65~75%, 개방 방 5~7개, 거점 후보 3개, 단서 2개 이상을 지나면 실제 방을 추론 가능하게 한다.
- 제5장: 공개 목표까지 굴착 구간 3개와 잠금 전투 방 2개를 직렬 배치한다. 방의 생존 적이 0이면 다음 파괴 불가 봉쇄가 열린다.
- 캠페인 영웅 AI는 `arena`, `companion`, `battle` 컨트롤러를 공유한다. companion은 9칸 내 교전 시 공용 영웅 전투 AI를 실행하고 비전투 시 플레이어를 따른다.
- 캠페인 적 생성은 장별 분산 spawn zone에서 가장 가까운 빈 열린 칸을 찾아 배치해 막힌 거점 좌표에서 큐가 영구 재시도되지 않게 한다.
- 1장 철각은 예비 객체로 보관했다가 2차 웨이브 잔존 침입체가 후반 기준 이하가 되면 `units`에 삽입한다. 산미 AI는 1차 웨이브 시작 전에는 정지한다.
- 2장 철각은 평택 거점 인접 칸의 `campaignGuard` 상태로 시작하고 살아 있는 박사와의 거리가 활성 반경 이내일 때만 전투 AI를 실행한다.
- 3장 전투 개시 기준은 `campaignIntroClock >= 6900ms`다. 대상별 짧은 넉백 면역 시간과 1칸 제한을 적용하고, 밀어낸 기술명을 월드 팝업으로 표시한다.
- 플레이어 굴착 이동은 현재 열린 길이 없더라도 목표를 폐기하지 않고 목표 방향의 파괴 가능한 경계 흙으로 재계획한다.
- 신규 벽 중심 맵은 기존 `BattleMapDefinition`과 테스트를 공유한다.

### 공용 이동 표현과 교착 회복

- 시뮬레이션 충돌은 기존 정수 타일 좌표를 유지하고, 렌더 좌표만 `moveFrom/moveTo/moveStartedAt/moveDuration` 상태로 smoothstep 보간한다. 새 이동이 이전 보간 도중 시작되면 현재 보간 좌표를 다음 시작점으로 사용해 끊김을 막는다.
- 타일 이동 성공은 `commitGridMove()` 한 경로로 통합해 진군대·AI 영웅·박사에게 같은 보간과 이동 예약을 적용한다.
- 진군대는 `blockedMs`가 누적되면 목적지 거리, 주변 혼잡도, 역주행, 프레임 예약을 점수화한 빈 인접 칸으로 양보한다. breaker는 장기 혼잡 시 측면 굴착을 우선하며, 복구 실패가 계속되면 탐색 목표와 노선 대기 상태를 갱신한다.
- `setRouteTarget()`은 사용자가 지정한 열린 타일 하나만 최종 point로 저장한다. 마지막 point의 assault objective도 탐색 목표로 치환하지 않고 `rallyGoal(point)`를 유지하며, 주변 적 반응이 끝나면 다시 해당 노선으로 복귀한다.

## 테스트

- 프레임 계획: 안서나 대기 flip 불변, 기술 슬롯별 좌우 대칭, R-486 대기 기준
- 전투: 근접 자동 접근 전에는 공격 판정 없음
- 맵: 7개 맵 후보쌍 대칭, seed 재현, 서로 다른 seed의 위치 다양성, 굴착 연결성
- 오디오: 사용자 입력 전 생성 금지, unlock 후 running 재개
- 캠페인: 제4장 숨은 거점, 제5장 공개 목표·전투 잠금 해제
- 브라우저: 프롤로그 최초/재진입, 영웅 상세 가독성, 결과 연출, 3개 viewport HUD 겹침
- 이동: 점유 교착에서 측면 양보 또는 재탐색, 연속 이동 중 보간 시작점 연결, 박사·진군대·AI 영웅 공통 보간
