# 평택 호송 박사 v1

- 용도: 휴먼 캠페인 제2장 `평택으로 가는 표본`의 민간인 호송 대상 3명
- 원본: `public/assets/campaign/scientists/scientists-v1.png`
- 생성 방식: built-in image generation
- 프롬프트 요약: 낡은 연구복·방진 조끼·헤드램프·녹색 표본 케이스를 든 비무장 일반인 연구원 3명의 지하 생존 게임용 픽셀아트 시트. 텍스트·로고·무기 없음.
- 적용: 제2장 브리핑 화면에 시각 에셋으로 연결했다. 실제 전투용 프레임 분리와 호송 AI는 제2장 수직 슬라이스에서 후속 적용한다.
