# 서울 지하 999M 캐릭터 이미지 보관 규칙

## 역할

- 이 디렉터리는 캐릭터 콘셉트, 액션 포즈와 생성 원본 스프라이트의 기준 보관소다.
- 실제 게임이 직접 불러오는 배포 에셋은 `4. 개발/seoul-999m-below/public/assets/characters/`에 별도 사본으로 둔다.
- 설계 원본과 런타임 사본을 분리해 게임 경로를 안정적으로 유지하면서 이전 디자인을 추적한다.
- 디렉터리명 `케릭터`는 현재 프로젝트에서 사용자가 지정한 기준 경로이므로 임의로 바꾸지 않는다.

## 폴더 구조

```text
3. 설계/케릭터/
└─ 휴먼/
   ├─ 유승천/
   │  ├─ 콘셉트/v1~v3/
   │  ├─ 액션포즈/v1~v2/
   │  └─ 게임스프라이트/v1/
   ├─ 김씨/콘셉트/v1~v2/
   ├─ 안서나/콘셉트/v1~v2/
   └─ 강력한/콘셉트/v1~v2/
```

버그본과 AI 로봇 이미지를 제작하면 `휴먼`과 같은 깊이로 종족 디렉터리를 추가한다.

현재 버그본과 AI 로봇은 개별 스프라이트 제작 전 단계이므로 종족별 `로스터/콘셉트/v1/`에 4인 비교 시트를 먼저 보관한다. 캐릭터 디자인이 승인되면 각 이름의 개별 디렉터리를 추가한다.

## 버전 정책

1. 기존 이미지를 덮어쓰지 않는다.
2. 외형이나 실루엣이 바뀌면 새 `v번호` 폴더와 파일을 만든다.
3. 투명 배경 정리, 프레임 크롭처럼 같은 디자인의 제작 보정은 파일명 뒤에 목적을 붙이되 원본을 함께 보존한다.
4. 문서에는 항상 사용할 정확한 버전 경로와 상태를 기록한다.
5. 게임에 채택할 때만 선택한 설계 이미지를 `4. 개발` 런타임 경로로 복사하고 코드와 테스트를 함께 갱신한다.

권장 파일명은 `[종족]-[캐릭터]-[자료종류]-v번호[-수정내용].png`다.
