## 최종 프롬프트 세트 요약

### 휴먼

김씨는 전자레인지 내려찍기·전기 조리·염력 굴착장·강제 조리, 안서나는 약액 분사·광역 치료·일직선 굴착·염산 원뿔, 강력한은 뚜껑 밀기·방어령·안전구역 봉쇄·뚜껑 투척을 서로 다른 전신 실루엣으로 제작한다. 기존 B급 장비와 의상, 비율과 행 순서를 보존한다.

### 버그본

철각은 턱 쓸기·껍질 돌격·쐐기굴·탈피 충각, 산미는 산성 침·산성 표식·직선 용해·위산 웅덩이, 회분은 눈가루·활강·십자 초음파·불나방 난무, 매듭은 웹 덫·실 당기기·실톱 굴착·팔방 봉쇄를 고유 생체 기관으로 표현한다.
