# 플레이 영웅 공용 액션 아틀라스 v1

## 제작 모드

- 모드: 신규 이미지 생성
- 목적: 유승천 외 11명을 실제 게임에서 즉시 구분하고 조작할 수 있는 1차 런타임 액션 시트
- 공통 규격: 고전 PC 액션 RPG풍 다크 도트, B급 수제 장비, 한 캐릭터당 가로 6포즈, 캐릭터별 한 행, 격자 경계·문자·UI 없음
- 포즈 순서: 대기, 이동 A, 이동 B, 공격 준비, 공격 타격, 피격/전투불능

## 생성 프롬프트 기록

### `human-roster-actions-v1-source.png`

휴먼 김씨·안서나·강력한 3명을 각 한 행에 배치한 3×6 액션 아틀라스. 김씨는 정장 차림의 거구와 테이프를 감은 전자레인지, 안서나는 빈민가 약제사 복장과 싸구려 분무기, 강력한은 장발 미소년 얼굴·근육질 체형·하수구 뚜껑 방패를 유지한다. 장비는 허접하지만 동작은 읽기 쉽고 역동적으로 표현한다.

### `bugborn-roster-actions-v1-source.png`

철각·산미·회분·매듭을 각 한 행에 배치한 4×6 액션 아틀라스. 거대한 턱의 돌격 벌레, 산성낭 변이체, 비상등을 좇는 나방 정찰자, 굳은실과 여러 팔을 쓰는 거미 함정가의 실루엣과 공격법을 명확히 구분한다. 빠르고 가벼운 종족 특성을 유지한다.

### `ai-roster-actions-v1-source.png`

D-09 땅파·G-77 야간반장·R-486 땜빵·C-999 국장을 각 한 행에 배치한 4×6 생성 원본. 공용 시트의 C-999 행은 작은 화면에서 외계인처럼 읽혀 전용 v2 시트로 교체했으며 원본은 변경 이력으로만 보관한다.

## 런타임 준비

`4. 개발/seoul-999m-below/scripts/prepare-hero-roster-atlas.mjs`가 가장자리와 연결된 배경을 투명 처리하고 휴먼은 768×384, 버그본·AI는 768×512로 정규화한다. 게임용 결과는 `public/assets/characters/sprites/roster-v1/`에 저장한다.

이 버전은 12명 플레이 가능 여부를 확인하는 공용 1차 시트다. 유승천의 개별 4방향 시트와 같은 완성도로 캐릭터별 시트를 제작하면 새 버전에 보관하고 순차 교체한다.
