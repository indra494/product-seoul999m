# 비밀 굴착전 기술 설계 v0.1

## 1. 상태와 목적

- 상태: `2026-08-26 2.25배 준비 가속·굴착기 광역화·접근권 AI 보정 구현·검증 완료`
- 기준 기획: `2. 기획/비밀-굴착전-핵심-기획-v0.1.md`
- 기준 커밋: `2fa1f5c`
- 목적: 기존 `개방 전선전`·캠페인·온라인 전투를 복제하지 않고, 규칙 계층을 추가해 팀 비공개 초고속 굴착과 30초 준비·4분 침공을 지원한다.

## 2. 모드 식별자

- `BattleRuleset = "secret-tunnel" | "open-front"`
- `MatchConfig`, 온라인 방 상태와 생성 요청에 `ruleset`을 포함한다.
- 컴퓨터 대전과 같이하기 모두 모드를 선택할 수 있으며 신규 기본값은 `secret-tunnel`이다.
- 캠페인은 `MatchConfig`를 사용하지 않는 기존 장별 규칙을 유지한다.

## 3. 규칙 모듈

`game/secretTunnelRules.ts`는 React와 Canvas에 의존하지 않는 순수 모듈로 둔다.

- 상수: 준비 30초, 침공 240초, 준비 중 1회 굴착으로 해당 팀의 남은 내구도 제거, 이동·연속 굴착 2.25배, 4번 재사용 25%
- 초고속 굴착: `secretTunnelRushDigDamage()`가 현재 팀의 잔여 내구도 이상을 반환한다. `secretTunnelPrepareDuration()`은 기존 준비 이동 95ms를 약 42ms, 기본 굴착 잠금 135ms를 60ms, AI 판단 90ms를 40ms로 줄인다. 이 분기는 `secret-tunnel + prepare`에만 적용한다.
- 전역 굴착기: `game/drillRules.ts`가 1.5배 도달 범위와 120ms 이동 잠금을 단일 기준으로 제공한다. 플레이어·컴퓨터·온라인 명령이 같은 값을 사용하고 이펙트 재생 시간은 이동 잠금과 분리한다.
- 페이즈: `prepare | assault | finished`
- 접근 마스크: `0=없음`, `1=청팀`, `2=적팀`, `3=공동`
- 타일 오버레이: 양 팀의 독립 굴착 내구도, 접근 마스크와 공동 핵심 구간
- 질의 함수: 팀별 굴착 가능·통행 가능·표시 가능 상태
- 페이즈 잠금: 통행 접근과 별도로 준비 중 상대 시야·표적·피해·직접 충돌을 차단
- 전선 판정: 직접 적 코어 도달 또는 적 코어 연결 터널 접촉
- 준비 종료: 한 팀 미연결은 고립 패배, 양 팀 미연결은 무승부
- 침공 종료: 코어 비율→방어막 비율→무승부
- A/B 배분: 균등 50:50, A 집중 75:25, B 집중 25:75

## 4. 지형과 터널 소유권

- 기존 `Tile.type/hp`는 원본 지형·개방 전선전·캠페인의 기준으로 유지한다.
- 비밀 굴착전은 같은 타일을 먼저 판 팀이 상대 팀의 벽 내구도까지 없애지 않도록 팀별 굴착 상태를 별도 overlay로 가진다.
- `openForTeam(tile, team)`은 원본 공용 지형과 overlay 접근 마스크를 함께 검사한다.
- 준비 중 상대 팀 전용 타일은 로컬 화면에서 기존 흙 또는 미확인 지형으로 그린다.
- 두 팀이 같은 타일의 독립 내구도를 모두 0으로 만들거나, 새로 열린 전용 타일의 상하좌우에 상대 전용 완성 타일이 있으면 해당 셀 쌍의 접근 마스크를 즉시 3으로 바꾼다. 대각선은 제외한다. 실제 공동 접촉은 준비 중에도 양 팀이 통행하며 이후 전용 접근으로 되돌리지 않는다.
- 준비 중 공동 접촉 타일의 통행 허용과 전투 잠금을 분리한다. 서로 같은 타일을 지나도 상대 객체 송신·표시, 적대 표적, 피해와 직접 충돌은 계속 차단한다.
- 개전 시 실제 공동 접촉 중 결정적 접촉점 하나를 선택하고 양 거점 주변 공동 구역에서 접촉점까지의 최단 핵심 구간을 접근 마스크 3으로 추가 승격한다. 선택되지 않은 실제 공동 접촉은 접근 마스크 3을 유지하되 그 접촉으로 이어진 비겹침 지선은 원래 팀 소유를 유지한다.
- 기존 X 접촉 격벽 상태와 렌더링은 제거한다. 접근 마스크 3인 실제 접촉은 준비·침공 모두 공동 통행으로 판정한다.
- 양 코어를 중심으로 처음부터 열린 주변 구역 전체를 접근 마스크 3으로 초기 배치한다. 별도 전실 자료형과 전용 렌더링은 두지 않는다.
- 개전 뒤 굴착·매립·4번 지형 행동은 비밀 굴착전에서 거부하고 HUD에 `지반 고정`을 표시한다.

## 5. 전투 페이즈

- 준비:
  - 웨이브 출전, 적대 공격, 투사체 피해와 상대 영웅 직접 충돌을 중지한다.
  - 자기 영웅·아군만 표시하고 양 거점은 항상 목표 표식으로 공개한다.
  - overlay 접근 마스크가 shared인 사전 개방 공간을 `seen/memory`에 일괄 등록하지 않는다. 적 거점 본체와 목표 표식만 안개 위에 별도로 그리며 공동 공간은 아군 시야가 닿을 때 탐사한다.
  - 실제 공동 접촉과 거점 주변 공동 구역의 양 팀 통행은 허용하되, 그 안에서도 상대 객체 시야와 전투 잠금을 유지한다.
  - 터널 접근 마스크의 색·사선·범례는 렌더링하지 않는다. 플레이어는 열린 지형과 자기 굴착 결과만 보고 준비한다.
  - 광석·크레딧·건설은 기존 대전 경제와 상한을 사용한다.
  - 컴퓨터 AI는 적 거점 방향의 유효 전선을 먼저 확보한 뒤 광석·방어 지선에 시간을 사용한다.
  - 1:1은 적 코어 공동 구역 안의 한 진입점, 2:2는 위·아래로 2칸 떨어진 두 진입점을 목표로 한다. 과거처럼 코어에서 옆으로 6칸 벗어난 지점을 최종 목표로 삼지 않는다.
  - 다음 굴착 칸이 막혀 있고 4번 지형 행동이 준비됐으면 플레이어와 같은 25% 재사용 규칙으로 즉시 사용한다. 유효 연결 전에는 광맥보다 코어 연결을 계속 우선한다.
  - 컴퓨터 영웅의 준비 행동 간격은 약 40ms를 기준으로 하며, 플레이어와 동일하게 한 번에 벽을 열고 그 칸으로 진입한다.
  - 컴퓨터전 적 팀은 시작부터 상대 코어 좌표를 공격 목표로 유지하고, 비밀 굴착전 웨이브는 A 75%·B 25%로 한 전선을 먼저 돌파한다.
- 개전:
  - 유효 연결과 결정적 공동 backbone을 확정하되 모든 실제 공동 접촉의 접근 마스크 3은 보존한다.
  - 고립 패배·쌍방 실패를 먼저 판정한다.
  - 모든 영웅의 명령·경로를 취소하고 팀별 코어 안전 셀로 재배치한 뒤 첫 웨이브를 출전한다.
  - 이 시점부터 유효 터널망 스캔, 아군·적군 전용 지역과 A/B 화살표를 표시한다. 공동 접근 타일은 렌더링하지 않는다.
- 침공:
  - 첫 웨이브를 즉시 출전하고 240초 타이머를 시작한다.
  - 영웅·진군대는 자기 팀 전용 또는 공동 터널만 통행한다.
  - 상대 전용 터널 geometry는 전체 공개하되 적색 전용 윤곽으로 그리며 접근권은 부여하지 않는다. 상대 영웅은 기존 일반 시야에 들어올 때만 표시한다.
  - 공동화되지 않은 대각선 접촉·부분 굴착 사이에는 거리·사거리만으로 교전하지 않는다. 공격자와 대상 사이의 적대 상호작용은 공동 접촉·공용 backbone·거점 주변 공동 구역의 실제 공동 접근을 통해 성립해야 한다.
  - 컴퓨터 영웅은 직선거리 안에 적이 있어도 자기 팀이 통행·교전할 수 없는 상대 전용 터널 안의 적을 표적으로 고정하지 않는다. 접근 불가능한 표적은 버리고 A/B 노선 또는 상대 코어 장기 목표를 계속 진행한다.

## 6. 거점 주변 공동 구역과 스폰 후보

- 각 코어를 중심으로 `openBases()`가 비운 Chebyshev 반경 4의 9×9 구역 전체를 초기 접근 마스크 3으로 승격한다.
- 이 공동 구역은 양 팀 pathfinding 후보에 포함하되 준비 중에는 통행만 허용하고 적대 시야·전투는 페이즈 잠금으로 막는다.
- 영웅·진군대는 자기 코어와 가까운 공동 빈 셀부터 스폰 후보를 정렬한다. 점유·설치물·코어 히트박스 검사는 기존 스폰 안전 조건을 재사용한다.
- 상대 코어 주변 셀은 자기 팀의 출전 후보로 사용하지 않는다.

## 7. A/B 경로와 표시

- 기존 전략 지점·최단 경로와 반대 회랑 계산을 재사용한다.
- A는 유효 최단 공격로, B는 A와의 중복을 최소화한 두 번째 경로를 우선 추천한다.
- 아군·적군 전용 타일은 각각 낮은 알파의 청록·적색 면으로 채운다. 같은 접근 마스크의 인접 셀 사이는 선을 그리지 않고, 다른 접근 마스크 또는 비터널과 맞닿는 네 방향 외곽선만 그려 연결된 지역을 큰 덩어리로 보이게 한다.
- 실제 공동 접촉, 공동 핵심 구간과 거점 주변 공동 구역은 색·사선·테두리·문자를 그리지 않는다. 접근 마스크 3과 양 팀 pathfinding 허용은 그대로 유지한다.
- 미니맵도 아군·적군 전용만 낮은 알파로 표시하고 공동 타일은 기본 지형색을 유지한다.
- A는 채운 화살표와 문자, B는 윤곽 화살표와 문자를 사용해 색상에만 의존하지 않는다.
- HUD는 `균등 / A 집중 / B 집중`을 제공하며 결정적 분배 함수가 웨이브 개체를 50:50·75:25·25:75로 배치한다.

## 8. 온라인 동기화

- 방 생성자가 선택한 `ruleset`을 방 상태에 저장하고 참가자는 변경하지 않는다.
- `OnlineBattleSnapshot`에 ruleset, phase, 절대 종료 시각, 팀 연결·A/B 배분과 터널 overlay를 포함한다.
- Worker는 준비 중 상대 영웅·진군대·설치물·상대 전용 터널·미공개 지형 변경을 송신 단계에서 필터링한다. 침공 전환 뒤에는 상대 전용 터널의 접근 마스크와 geometry만 보내고 내구도·굴착 주체·소유자 정보는 계속 숨긴다.
- 실제 공동 접촉과 양 거점 주변 공동 구역은 양 팀 view에 공동 접근으로 포함하되, 준비 중 그 위의 상대 영웅·진군대와 적대 효과는 계속 필터링한다. 통행 공개와 상대 객체 공개를 같은 조건으로 묶지 않는다.
- 준비 종료와 경기 종료는 `preparationEndsAt`, `matchEndsAt` 절대 시각을 기준으로 맞춘다. Worker 알람은 같은 시각보다 750ms 늦게 최종 판정해 직전 방장 스냅샷·종료 메시지와 경합하지 않는다.
- 방장 재접속은 스냅샷의 `lastAppliedCommandSequence` 이후 명령만 중복 제거해 재생한다. 매 프레임 저장 스냅샷을 페이즈 종료 판정과 명령 재생보다 먼저 복원한다.
- 모바일 이동, 생존기, 업그레이드와 철거도 온라인 명령으로 동기화한다. 개인 소모품은 별도 권위 상태를 추가하기 전까지 온라인에서 비활성화한다.
- 현재 방장 권위 전투 구조는 유지하되 팀별 view 생성 함수로 송신 데이터를 분리한다.
- 온라인 명령 허용 목록은 클라이언트의 `OnlineBattleCommand`와 항상 동일하게 유지한다.

## 9. HUD와 첫 플레이 안내

- 경기 진입에는 `터널 뚫기 시작 · 30초`, 개전에는 `거점 공격 시작 · 영웅 전원 귀환` 중앙 팝업을 표시하고, 상단에는 `비밀 굴착 00:29` 또는 `침공 03:59`를 지속 표시한다.
- 종료 15초·5초에 유효 전선이 없으면 `종료 시 고립 패배`를 경고한다.
- 첫 준비 단계 안내는 `적 거점 확인 → 터널 연결 → 광석·방어 선택`의 3단계로 짧게 표시한다.
- 4번 버튼은 준비 중 `굴착`, 개전 뒤 `지반 고정`으로 표시하고 비활성화한다.
- 하단 상시 조작 문장은 핵심 입력만 남기고 세부 조작은 도움말과 툴팁으로 이동한다.
- 모바일 코어 제목은 `아군 코어`·`적 코어`로 압축한다.
- 준비 중에는 터널 접근 범례를 숨긴다. 침공 전투의 터널 범례는 `아군 전용 / 적군 전용` 두 개만 표시한다. 공동 터널은 무표시이며 A/B 진군 방향은 기존 별도 화살표로 전달한다.

### 비밀 굴착전 전용 맵

- `matchConfig.ts`에 전용 ID `secret-crossroads`, `secret-reservoir`, `secret-cache`를 추가한다.
- `battleMaps.ts`는 `SECRET_TUNNEL_MAPS` 3종과 `OPEN_FRONT_BATTLE_MAPS` 7종을 분리하고 ruleset에 맞는 목록만 선택 UI에 제공한다.
- 전용 맵은 고정 좌우 대칭 코어 좌표를 사용한다. `applyBattleMapLayout`이 미리 비운 코어 외부 셀은 overlay 초기화에서 접근 마스크 3의 공용 공간으로 등록한다.
- 공용 방은 양 코어 사이를 처음부터 완전히 잇지 않으며 각 팀 코어와 최소 한 칸 이상의 굴착 구간을 남긴다.
- `applyBattleMapLayout`은 비밀 굴착전 맵에 회전 대칭 광맥을 추가한다. 열린 공간·영구 장애물·코어 반경은 제외하고 맵마다 `ore`가 있는 굴착 벽 24칸 이상을 자동 테스트로 보장한다.

## 11. 회귀·완료 기준

1. 개방 전선전과 캠페인의 기존 굴착·전투·승패 테스트가 그대로 통과한다.
2. 양 팀 굴착 내구도는 독립으로 유지되며, 동일 타일 양측 굴착 완료 또는 상하좌우 인접 완성 터널은 즉시 실제 공동 접촉으로 전환돼 준비 중 양 팀이 통행한다.
3. 모든 실제 공동 접촉은 공동 상태를 보존하고, 개전 시 선택된 핵심 backbone만 추가 공동화하며 비겹침 지선은 비공개·전용이다.
4. 준비 중 사전 개방 공동 공간은 미리 탐사되지 않으며 적 거점만 안개 위에 목표로 보인다. 공동 접촉과 거점 주변 공동 구역을 통행해도 상대 캐릭터·상대 전용 터널·적대 피해·직접 충돌이 보이거나 적용되지 않는다.
5. 한 팀 고립 패배와 양 팀 실패 무승부가 결정적으로 판정된다.
6. 개전 뒤 굴착·매립·4번이 잠기고 영웅 전원 코어 귀환, 첫 웨이브, A/B 배분·4분 판정이 순서대로 작동한다.
7. 컴퓨터와 온라인 양쪽에서 두 모드를 선택해 완주할 수 있다.
8. 프로덕션 빌드, 전체 자동 테스트, lint의 새 오류 0건과 데스크톱·모바일 브라우저 콘솔 오류 0건을 확인한다.
9. 양 코어 중심 반경 4의 열린 9×9 구역 전체가 공동 접근으로 생성되고 출전은 자기 코어에 가까운 공동 빈 셀을 선택한다.
10. 시작·개전 팝업, 전용 맵 3종, 침공 뒤 적 전용 터널 표시와 준비·침공 AI의 지속 행동을 확인한다.
11. 준비 중에는 터널 접근 표기가 없고, 개전 뒤 아군·적군 전용 지역만 옅은 연결 면과 외곽선으로 표시한다. 공동 구역은 전장·미니맵에서 별도 표시하지 않는다.
12. `비밀 굴착전 ↔ 개방 전선전` 전환 시 각 ruleset의 기본 `BattleMapId` 문자열이 항상 유효하며 선택 화면 렌더에서 `undefined` 맵 조회가 발생하지 않는다.
13. 컴퓨터 준비 AI의 목표가 적 코어 공동 반경 안이며 1:1·2:2 모두 30초 안에 최소 한 유효 연결을 만들 수 있는지 검사한다.
14. 침공 뒤 컴퓨터 영웅과 진군대가 자기 A/B `plannedCells`를 따라 아군 코어까지 진행하고, 일시적 아군 혼잡을 경로 단절로 오판해 후퇴하지 않는지 검사한다.
15. 컴퓨터 영웅은 혼잡으로 옆 칸을 사용한 뒤 지나온 경로 포인트로 돌아가지 않고 최대 10칸 앞의 도달 지점으로 커서를 복구하며, 저체력이어도 적 코어 공세 목표를 버리지 않는다.

### 2026-08-26 규칙 보정 구현·검증 결과

- `secretTunnelRules.ts`에 준비 중 공동 접촉 통행, 실제 겹침 보존과 거점 주변 9×9 공동 구역을 반영하고 런타임에 자기 코어 인접 스폰과 모든 특수 공격의 접근권 검사를 연결했다. `durabilityAt`은 원래 타일의 `hp/max`를 보존하되 준비 중에는 잔여 내구도 전량을 1회 굴착 피해로 사용한다.

- 완성된 양 팀 전용 터널의 상하좌우 접촉 공동화, 침공 뒤 적 전용 geometry 공개·통행 거부, 개전 시 전 영웅 코어 귀환, 시작·개전 팝업과 연결 후에도 광석·우회로를 파는 AI를 런타임과 온라인 팀별 view에 연결했다.
