# 서울 지하 999M 오프닝 v2

## 상태

- `검토 중`: 사용자가 지정한 프롤로그 14문장을 축약·개작하지 않고 그대로 사용한 수정본이다.
- v1은 보존하며 v2를 현재 검토 대상으로 사용한다.
- 게임 시작 흐름에는 아직 연결하지 않았다.
- 음성 내레이션은 없고 오리지널 배경음과 타자음이 포함되어 있다.

## 결과물

- 영상: `seoul-999m-opening-v2.mp4`
- 규격: 1920×1080, H.264 MP4, 99초, 약 42.4MB
- 오디오: 스테레오 48kHz
- 렌더 소스: `../../../../4. 개발/seoul-999m-below/tools/opening-v2-render.html`
- 렌더 실행기: `../../../../4. 개발/seoul-999m-below/tools/render-opening-v2.mjs`

## 확정 입력 원문

> 지상은 죽었다.
>
> 하늘은 독성 먼지로 뒤덮였고, 인류는 더 이상 그곳에서 숨을 쉴 수 없었다.
>
> 살아남은 사람들은 땅속으로 내려갔다.
>
> 지하 999미터. 과거에 건설된 공기 정화층이 아직 작동하는, 마지막 생존 가능 구역이었다.
>
> 서울도 그곳에 새로운 도시를 세웠다.
>
> 전력망과 공장, 통신망은 무너졌고 사람들은 버려진 기계와 고철을 이어 붙이며 문명을 다시 시작했다.
>
> 세계의 지하 도시들은 비밀 터널로 연결되었다.
>
> 자원과 연구 자료가 오갔고, 각 도시의 연구자들은 언젠가 지상을 되살리기 위한 연구를 계속했다.
>
> 하지만 터널을 통해 오간 것은 희망만이 아니었다.
>
> 부족한 자원, 정체불명의 생물, 그리고 주인을 잃은 기계들이 도시 사이의 어둠을 차지하기 시작했다.
>
> 나는 서울의 ‘두더지’다.
>
> 땅을 파고, 자원을 찾고, 새로운 도시로 향하는 길을 만드는 사람.
>
> 오늘도 평범한 굴착 작업이어야 했다.
>
> 우리가 먼저 이곳에 온 것이 아니라는 사실을 발견하기 전까지는.

렌더 전 자동 비교에서 14문장 모두 원문과 글자·문장부호가 일치함을 확인했다. 화면 줄바꿈만 추가했다.

## 배경음 구성

- 외부 음원을 사용하지 않은 오리지널 절차적 다크 앰비언트다.
- 지하 환기 설비를 연상시키는 저주파 드론과 필터 노이즈
- 11초 단위로 느리게 변하는 단조 화음
- 약 3.2초 간격의 낮은 맥박음
- 장면 전환마다 울리는 짧은 금속 공명
- 위협이 등장하는 후반부의 불협화 긴장음
- 글자가 나타날 때의 짧은 타자 입력음

## 이미지 생성 방식과 최종 프롬프트 세트

- 생성 방식: Codex 내장 `imagegen`
- 공통 스타일: 16:9 게임 오프닝용 고밀도 시네마틱 2D 도트 일러스트, 고전 한국 PC RPG 분위기, 숯빛 검정·뼛빛 회색·검붉은 녹·희미한 청록 비상등, 글자·로고·UI·워터마크 없음
- `scene-01`: 독성 먼지와 폐허에 잠긴 서울 지상
- `scene-02`: 생존자 승강기가 끝없는 수직 갱도를 따라 하강
- `scene-03`: 999m 지점에서 간신히 작동하는 거대 공기 정화층과 처음 마스크를 벗는 생존자
- `scene-04`: 폐열차·컨테이너·환기 덕트와 고철로 재건한 지하 서울
- `scene-05`: 무너진 전력망·공장·통신 시설에서 고철과 버려진 기계로 문명을 재건하는 작업장
- `scene-06`: 지하 도시를 연결하며 자원과 연구 자료가 오가는 비밀 터널 분기점
- `scene-07`: 버려진 자원 수레 주변을 차지한 미확인 지하 생물 실루엣과 주인을 잃은 산업 기계
- `scene-08`: 오른팔 고철 드릴과 왼손 장난감검을 든 유승천이 미확인 폐시설을 발견하는 장면
