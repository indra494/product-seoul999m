# 서울 지하 999M 오프닝 v3

## 상태

- `검토 중`: 사용자 요청에 따라 v2의 99초 구성을 30초로 압축하고 한국어 여성 나레이션을 추가한 버전이다.
- v1과 v2는 그대로 보존한다.
- 게임 시작 흐름에는 아직 연결하지 않았다.

## 결과물

- 영상: `seoul-999m-opening-v3.mp4`
- 규격: 1920×1080, H.264 MP4, 30.001초, 약 14.2MB
- 오디오: 영상 내 오디오 트랙 1개, 여성 나레이션과 오리지널 다크 앰비언트 배경음
- 여성 나레이션 원본: `audio/narration-female-heami.wav`
- 음성·장면 동기화 정보: `audio/narration-timings.json`
- 대표 화면 검수본: `review/`
- 렌더 소스: `../../../../4. 개발/seoul-999m-below/tools/opening-v3-render.html`
- 렌더 실행기: `../../../../4. 개발/seoul-999m-below/tools/render-opening-v3.mjs`
- 나레이션 생성기: `../../../../4. 개발/seoul-999m-below/tools/create-opening-v3-narration.ps1`

## 편집 원칙

- 화면에는 사용자가 지정한 프롤로그 14문장을 축약·개작하지 않고 그대로 표시한다.
- 30초 안에서 읽을 수 있도록 8개 장면에 문장을 묶고 화면당 최대 4줄을 사용한다.
- 글자는 장면 초반 약 0.4~0.8초 동안 빠르게 나타난 뒤 나레이션이 끝날 때까지 유지한다.
- 나레이션은 `Microsoft Heami Desktop` 한국어 여성 음성을 사용하며 최고 속도인 `Rate 10`으로 생성했다.
- 화면의 `999`는 의미가 분명하도록 음성에서 `구백구십구`로 발음하고, 인용 부호는 발음하지 않는다. 화면 원문은 변경하지 않는다.
- 나레이션 길이는 26.3386초이며 0.5초부터 재생한다. 타이틀은 27.55초부터 30초까지 표시한다.
- 저주파 드론·환기 노이즈·맥박음·타자음을 나레이션 아래로 낮게 믹스했다.

## 확정 입력 원문

> 지상은 죽었다.
>
> 하늘은 독성 먼지로 뒤덮였고, 인류는 더 이상 그곳에서 숨을 쉴 수 없었다.
>
> 살아남은 사람들은 땅속으로 내려갔다.
>
> 지하 999미터. 과거에 건설된 공기 정화층이 아직 작동하는, 마지막 생존 가능 구역이었다.
>
> 서울도 그곳에 새로운 도시를 세웠다.
>
> 전력망과 공장, 통신망은 무너졌고 사람들은 버려진 기계와 고철을 이어 붙이며 문명을 다시 시작했다.
>
> 세계의 지하 도시들은 비밀 터널로 연결되었다.
>
> 자원과 연구 자료가 오갔고, 각 도시의 연구자들은 언젠가 지상을 되살리기 위한 연구를 계속했다.
>
> 하지만 터널을 통해 오간 것은 희망만이 아니었다.
>
> 부족한 자원, 정체불명의 생물, 그리고 주인을 잃은 기계들이 도시 사이의 어둠을 차지하기 시작했다.
>
> 나는 서울의 ‘두더지’다.
>
> 땅을 파고, 자원을 찾고, 새로운 도시로 향하는 길을 만드는 사람.
>
> 오늘도 평범한 굴착 작업이어야 했다.
>
> 우리가 먼저 이곳에 온 것이 아니라는 사실을 발견하기 전까지는.
