# 서울 지하 999M 오프닝 v9 — 고정 오디오 타임라인

- `검토 중`: 시작부터 끊김 소리가 들리던 문제를 구조적으로 수정한 20초 프롤로그다.
- v1~v8은 보존한다.

## 수정 내용

- 실시간 나레이션·경보 발생기를 제거했다.
- 나레이션과 경보를 미리 하나의 20초 PCM 음원 `audio/opening-final-mix.wav`로 합성했다.
- MP4 녹화를 시작한 뒤 완성 음원을 재생하므로 오디오 시작 시점이 앞당겨지지 않는다.
- 0~0.35초는 무음, 0.35~14.78초는 여성 나레이션, 14.8~16.8초는 경보·찢김음, 17초 이후는 무음이다.
