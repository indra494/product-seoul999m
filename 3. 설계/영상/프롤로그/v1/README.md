# 서울 지하 999M 오프닝 v1

## 상태

- `검토 중`: 사용자 원안을 바탕으로 만든 첫 영상 초안이다.
- 프롤로그 문구, 45초 길이, 장면 구성과 음성 추가 여부는 최종 확정 전이다.
- 게임 시작 흐름에는 아직 연결하지 않았다.

## 버전 보관 규칙

- 프롤로그 원본은 `3. 설계/영상/프롤로그/v번호/` 단위로 보관한다.
- 각 버전의 완성 영상과 README는 버전 폴더 바로 아래에 둔다.
- 해당 버전에서 사용한 생성 이미지와 로고는 `images/`에 보관한다.
- 다음 수정본은 기존 파일을 덮어쓰지 않고 `v2`, `v3` 폴더를 새로 만든다.

## 결과물

- 영상: `seoul-999m-opening-v1.mp4`
- 규격: 1920×1080, H.264 MP4, 약 45초
- 오디오: 저주파 지하 기계음과 타자 입력음. 음성 내레이션은 없음
- 렌더 소스: `../../../../4. 개발/seoul-999m-below/tools/opening-v1-render.html`
- 렌더 실행기: `../../../../4. 개발/seoul-999m-below/tools/render-opening-v1.mjs`

## 화면 문구

1. `환경오염으로 지상은 / 사람이 살 수 없는 곳이 되었다.`
2. `인류는 숨을 쉬기 위해 내려갔다. / 지하 999미터까지.`
3. `서울도 그곳에 새로운 도시를 세웠다. / 햇빛 대신, 조명만이 남았다.`
4. `도시들은 비밀 터널로 이어졌고, / 연구자들은 지상을 되살릴 방법을 찾았다.`
5. `나는 서울의 ‘두더지’다. / 오늘도 자원과 새로운 길을 찾아 땅을 판다.`
6. `그날, 열어서는 안 될 길을 / 열기 전까지는.`

## 이미지 생성 방식과 최종 프롬프트 세트

- 생성 방식: Codex 내장 `imagegen`
- 공통 스타일: 16:9 게임 오프닝용 고밀도 시네마틱 2D 도트 일러스트, 고전 한국 PC RPG 분위기, 큰 픽셀 덩어리와 회화적 픽셀 명암, 숯빛 검정·뼛빛 회색·검붉은 녹·희미한 청록 비상등, 글자·로고·UI·워터마크 없음
- 장면 1: 독성 먼지와 폐허에 잠긴 서울 지상, 남산서울타워 실루엣, 버려진 도로와 부식된 건물
- 장면 2: 생존자들이 탄 고철 승강기가 끝없는 수직 갱도를 따라 지하로 내려가는 장면
- 장면 3: 폐열차·컨테이너·환기 덕트와 고철로 재건한 지하 서울의 생활 구역
- 장면 4: 여러 도시로 갈라지는 비밀 터널 분기점에서 토양·균류·공기를 연구하는 연구자와 자원을 운반하는 작업자
- 장면 5: 기존 유승천 콘셉트 시트를 외형 참조로 사용. 오른팔 고철 드릴과 왼손 장난감검을 든 유승천이 굴착 끝에 거대한 폐시설과 붉은 눈을 발견하는 장면
