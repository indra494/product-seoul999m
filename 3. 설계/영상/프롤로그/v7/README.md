# 서울 지하 999M 오프닝 v7 — 축약 극장식 스크롤

## 상태

- `검토 중`: 게임 시작용 20초 극장식 오프닝이다.
- v1~v6는 보존한다.

## 결과물

- 영상: `seoul-999m-opening-v7.mp4`
- 규격: 1920×1080, H.264 MP4, 20.0020초, 약 10.5MB
- 오디오: 초반 여성 나레이션, 오리지널 산업 배경음, 경보음과 신호 단절음
- 여성 나레이션 원본: `audio/narration-female-heami.wav` (Microsoft Heami Desktop, 한국어 여성 음성, 속도 +5)
- 대표 화면 검수본: `review/`

## 연출 규칙

- 축약 원문 10문장을 하단에서 상단으로 계속 흘리는 극장 엔딩 방식으로 표시한다. 타자식 로그·상단 정보창은 사용하지 않는다.
- 배경은 폐허 서울 → 하강 갱도 → 공기 정화층 → 지하 서울 → 비밀 터널 → 위협 → 발견 장면 순서로 바뀐다.
- 여성 나레이션은 `지상은 죽었다.`부터 읽고, `지하 구백구십구…` 도중 경보가 덮치며 강제로 끊긴다.
- 14.8초부터 `띠리리리, 띠리리리` 경보음과 함께 화면 가로 찢김·적청 색 분리·노이즈·`SIGNAL FAULT` 문구를 표시한다.
- 16.8초부터 발견 장면의 저음만 남기며, 18초부터 투명 로고를 표시한다.

## 기준 원문

> 지상은 죽었다.
>
> 하늘은 독성 먼지로 뒤덮였고, 인류는 더 이상 그곳에서 숨을 쉴 수 없었다.
>
> 살아남은 사람들은 땅속으로 내려갔다.
>
> 지하 999미터. 과거에 건설된 공기 정화층이 아직 작동하는, 생존 가능 구역이었다.
>
> 서울도 그곳에 새로운 도시를 세웠다.
>
> 각 도시의 연구자들은 언젠가 지상을 되살리기 위한 연구를 계속했다.
>
> 우리는 서울의 ‘두더지’ 대원이라고 불린다.
>
> 땅을 파고, 자원을 찾고, 새로운 도시로 향하는 길을 만드는 사람.
>
> 오늘도 평범한 굴착 작업이어야 했다.
>
> 우리가 먼저 이곳에 온 것이 아니라는 사실을 발견하기 전까지는.
