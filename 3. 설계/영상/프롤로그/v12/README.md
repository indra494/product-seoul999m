## 기준 원문

> 지상은 죽었다.
>
> 하늘은 독성 먼지로 뒤덮였고, 인류는 더 이상 그곳에서 숨을 쉴 수 없었다.
>
> 살아남은 사람들은 땅속으로 내려갔다.
>
> "지하 999미터" 과거에 건설된 공기 정화층이 아직 작동하는, 생존 가능 구역이었다.
>
> 서울도 그곳에 새로운 도시를 세웠다. 각 도시의 연구자들은 언젠가 지상을 되살리기 위한 연구를 계속했다.
>
> 우리는 서울의 ‘두더지’ 대원이라고 불린다.
>
> 땅을 파고, 자원을 찾고, 새로운 도시로 향하는 길을 만드는 사람.
>
> 오늘도 평범한 굴착 작업이어야 했다.
