# 서울 지하 999M 오프닝 v4

## 상태

- `검토 중`: v3의 빠른 나레이션을 개선하고 배경음의 존재감과 후반 긴장을 강화한 42초 버전이다.
- v1~v3는 그대로 보존한다.
- 게임 시작 흐름에는 아직 연결하지 않았다.

## 결과물

- 영상: `seoul-999m-opening-v4.mp4`
- 규격: 1920×1080, H.264 MP4, 41.9967초, 약 19.6MB
- 오디오: 영상 내 오디오 트랙 1개, 여성 나레이션과 오리지널 다크 앰비언트 배경음
- 여성 나레이션 원본: `audio/narration-female-heami.wav`
- 음성·장면 동기화 정보: `audio/narration-timings.json`
- 대표 화면 검수본: `review/`

## v3에서 변경한 내용

- 한국어 여성 음성 속도를 `Rate 10`에서 `Rate 7`로 낮췄다.
- 나레이션 길이를 26.3386초에서 36.3695초로 늘려 발음을 또렷하게 만들었다.
- 전체 영상 길이를 30초에서 42초로 늘렸다.
- 배경음 레벨을 높이고 7초 단위의 저음 화음 진행을 추가했다.
- 지하 환기 노이즈, 약 3초 간격의 박동과 후반 불협화 긴장음을 함께 사용했다.
- 마지막 문장이 끝난 뒤 약 1.6초 동안 발견 장면과 음악만 남겨 반전의 여운을 만든 뒤 로고로 전환한다.

## 지루함 방지 구성

- 원문 14문장을 8개 장면으로 묶어 약 1.7~6.1초마다 이미지와 카메라 움직임이 바뀐다.
- 화면당 최대 4줄을 사용하고 장면 초반에 자막을 빠르게 완성해 읽는 시간을 확보한다.
- 초반은 낮은 드론, 중반은 박동과 화음, 후반은 불협화 긴장음으로 음향 밀도를 단계적으로 올린다.
- 마지막 3.2초는 검은 배경과 로고로 정리한다.

## 원문과 발음 정책

- 화면에는 사용자가 지정한 프롤로그 14문장을 축약·개작하지 않고 그대로 표시한다.
- 화면의 `999`는 음성에서 `구백구십구`로 읽고 인용 부호는 발음하지 않는다.
- 정확한 화면 원문은 v3와 동일하며 렌더 전 자동 비교로 일치를 확인한다.

## 이미지

- v3의 배경 8장과 로고를 `images/`에 복사해 v4 자체 원본으로 보존했다.
- `scene-05-scrap-rebuilding.png`는 42초 편집에서도 지하 서울 장면에 통합했지만 원본 파일은 보존한다.
