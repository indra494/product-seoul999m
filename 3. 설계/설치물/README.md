## 공통 시각 규칙

- 동일한 3/4 탑다운 시점과 고전 PC 액션 RPG풍 2D 픽셀 표현을 사용한다.
- 화면은 어둡고 불길하게 유지하고, B급 감성은 허술한 재료와 과하게 진지한 기능에서 만든다.
- 휴먼은 생활 폐품·테이프·함석, 버그본은 뿌리·갑각·균사·뼈, AI 로봇은 폐산업 설비·센서·경고등으로 구분한다.
- 멋진 완제품이나 매끈한 SF 병기보다 고장 날 듯하지만 실제로 작동하는 외형을 우선한다.
- 작은 게임 화면에서도 공격 방향과 차단벽 실루엣이 분명해야 한다.

## v1 검토 메모

### 휴먼

- 벙커 내부의 여러 사람이 동시에 돌을 던지는 기능이 즉시 읽힌다.
- 캔미사일 포대는 생활 폐품 조립 인상이 나지만 최종본에서는 로켓을 조금 더 찌그러뜨려 완성품 느낌을 낮출 수 있다.
- 방어벽은 다섯 겹과 다양한 재료가 보이지만 게임용에서는 폭을 한 타일 규격으로 단순화해야 한다.

### 버그본

- 뿌리매복체는 낮고 넓으며 여러 뿌리팔로 공격해 기존의 단일 가시형 구조물과 구분된다.
- 독침나무는 독낭과 발사구가 분명하며 원거리 다중 공격 역할이 읽힌다.
- 잡뼈 방벽은 뼈, 갑각과 이빨의 방향성을 줄여야 게임 충돌 폭과 일치한다.

### AI 로봇

- CCTV 센서와 긴 포신으로 직선 관통 공격이 분명하다.
- 쌍발미사일기는 정확히 두 발과 무거운 재장전 구조가 보인다.
- 철갑격벽은 세 종족 중 가장 높은 내구도를 가장 직접적으로 표현한다.

## 게임 에셋 전환 조건

- 각 시트가 승인된 뒤 설치물별로 분리된 투명 PNG를 새 버전 폴더에 제작한다.
- 논리 점유는 기본 한 타일이며, 시각물은 타일 밖으로 나갈 수 있지만 충돌 중심과 바닥 접점은 한 칸 중앙에 고정한다.
- 공격 설치물은 대기, 조준, 발사, 피격, 파괴 애니메이션이 필요하다.
- 차단벽은 정상, 중파, 대파, 파괴의 네 단계가 필요하다.
- 콘셉트 원본을 잘라서 바로 런타임에 사용하지 않는다.

### 5겹 방어벽돌 v2

- 사용자 플레이 화면 검수에서 v1을 여러 칸 연속 배치하면 거대한 수직 기둥처럼 합쳐져 길목 차단물로 읽히지 않는 문제가 확인됐다.
- `휴먼/v2/게임에셋/human-five-layer-wall-v2-alpha.png`에 낮고 넓은 바리케이드형 투명 PNG를 새 버전으로 보관한다.
- 런타임은 `public/assets/buildables/human/human-five-layer-wall-v2-alpha.png`를 사용하며 v1은 삭제하거나 덮어쓰지 않는다.
- 최종 생성 프롬프트 요약: v1의 폐벽돌·함석·시멘트·전선·청록 비상등과 3/4 탑다운 픽셀 화풍은 유지하고, 높이를 약 45%로 낮추며 바닥 폭을 넓힌 단일 바리케이드로 변경. 실제 알파 투명 배경, 체크무늬·문자·상표·추가 구조물 금지.

## 생성 방식과 최종 프롬프트 세트

- 생성 방식: Codex 내장 이미지 생성 도구
- 사용 사례: `stylized-concept`
- 공통 조건: 정확히 세 설치물, 3/4 탑다운, 고전 한국 PC 액션 RPG풍 픽셀 아트, 어두운 지하 공포와 B급 감성, 글자·상표·워터마크 제외

### 휴먼 프롬프트

`흙·모래주머니 벙커 안의 여러 생존자가 낮은 사격구로 돌을 동시에 던지는 구조물, 찌그러진 음료수 캔·싸구려 불꽃놀이·선풍기 모터·노출 전선·테이프로 만든 빠른 단발 미사일 포대, 서로 다른 아파트 벽돌과 젖은 시멘트·테이프로 만든 다섯 겹 방어벽을 왼쪽부터 분리 배치. 싸구려 함석·진흙·벽돌·그을음·캔의 질감, 녹슨 갈색과 더러운 회색, 작은 청록 비상등. 매끈한 SF·군용 완제품·귀여운 장난감 형태 금지.`

### 버그본 프롬프트

`갈라진 번데기 둔덕에서 네 개의 가늘고 근육질인 뿌리팔이 여러 방향으로 나온 낮고 넓은 매복체, 뼈·균사·갑각으로 자란 줄기와 여러 독침 포드를 가진 독침나무, 갈비뼈·이빨·갑각 파편·마른 진흙의 불규칙 방벽을 왼쪽부터 분리 배치. 멍든 갈색·뼛빛·병든 올리브·탁한 보라와 독성 녹색 발광. 특정 기존 게임의 단일 거대 가시 구조물과 닮지 않게 하고 귀여운 벌레 형태 금지.`

### AI 로봇 프롬프트

`폐 CCTV·복사기 레이저 부품·가늘고 비뚤어진 포신과 붉은 조준 센서로 만든 직선 관통 광선기, 서로 높이가 다른 공업용 로켓 정확히 두 발과 노출 유압 장치를 얹은 무거운 궤도식 발사대, 엘리베이터 문·찌그러진 철판·볼트·고장 난 경고등으로 압착한 철갑격벽을 왼쪽부터 분리 배치. 숯빛 철·녹·더러운 베이지·바랜 안전 노랑, 붉은 센서와 청록 전력광. 매끈한 미래 병기·클린 메카·인간형 로봇 금지.`
