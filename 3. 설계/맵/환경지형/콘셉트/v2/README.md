- 기획 기준: `2. 기획/맵-환경지형-제안-v0.1.md`

## 목표

공통 지형 v1의 연결형 흙 표현 위에 큰 뿌리, 물길과 단차를 덩어리 단위로 추가해 전장 전체 실루엣을 극적으로 바꾼다. 새 지형은 장식이 아니라 통행 가능 여부와 우회 선택을 시각적으로 전달해야 한다.

## 시각 언어

### 거대 뿌리벽

- 타일 안에 작은 뿌리를 반복하지 않고 3~8칸을 가로지르는 굵은 줄기 하나로 연결한다.
- 적갈색 껍질, 회백색 곰팡이와 약한 청록 포자를 사용한다.
- 영구 장애물은 검은 틈과 두꺼운 접지 그림자로 바닥과 분리한다.

### 잔뿌리 덩어리

- 흙 표면 위에 가는 뿌리가 매듭처럼 얽힌 형태다.
- 굴착 피해에 따라 뿌리 수가 줄고 마지막에 흙이 무너진다.
- 거대 뿌리보다 밝고 가늘게 표현해 파괴 가능함을 전달한다.

### 깊은 배수로

- 청록빛 검은 물, 콘크리트 턱과 황색 경고선으로 구성한다.
- 물결은 2~3프레임의 느린 수평 이동만 사용하고 지나친 반사는 피한다.
- 폭 1~2칸의 긴 곡선 또는 S자 흐름으로 배치한다.

### 얕은 침수 통로

- 기존 통로 바닥이 보이도록 35~45% 투명 물막을 사용한다.
- 발밑 잔물결과 작은 물방울로 이동 저하 구역임을 알린다.
- 깊은 배수로보다 밝고 턱이 없어 걸을 수 있다는 차이를 만든다.

### 붕괴 단차와 경사로

- 높은 작업대는 바닥 상단에 밝은 테두리, 절벽 면에 10~14px 어두운 옹벽과 낙하 그림자를 둔다.
- 경사로는 사선 경고선, 난간 파손과 바닥 방향선을 사용한다.
- 캐릭터 스프라이트의 실제 크기나 z좌표를 바꾸지 않는다.

## 연결 마스크

- 뿌리벽: 상하좌우 연결 16마스크 + 끝단 2변형
- 깊은 배수로: 직선·모서리·T자·막힘 12마스크
- 단차: 상하좌우 절벽 외곽 16마스크 + 경사로 4방향
- 얕은 물: 통로 위 반투명 오버레이 4변형

## 런타임 단계

1. 현재 전장 생성 후 큰 영역 마스크를 만든다.
2. 거점 안전 반경과 3개 이상 유효 경로를 검사한다.
3. 뿌리벽·배수로·단차를 영구 장애물 레이어에 배치한다.
4. 잔뿌리와 얕은 물을 상호작용 지형 레이어에 배치한다.
5. Canvas에서 연결 마스크와 좌표 해시 변형을 합성한다.
6. 자동 진군대 길찾기와 점프 착지 가능 여부를 검사한다.
