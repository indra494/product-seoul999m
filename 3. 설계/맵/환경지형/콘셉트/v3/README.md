# 환경 지형 비주얼 콘셉트 v3

## 상태

- 분류: 사용자 지적을 반영한 최신 도트 비주얼 기준
- 기준 이미지: `seoul-999m-modern-pixel-environment-v3.png`
- 이전 기준: `../v2/README.md`

## 개편 목표

40px 타일 하나마다 큰 기호를 반복하는 임시 도형 표현을 폐기한다. 여러 칸이 하나의 흙 지층, 물길, 금속 시설과 뿌리 덩어리로 이어져 보이게 만들고 캐릭터보다 배경이 튀지 않으면서도 재질은 즉시 구분되게 한다.

## 렌더링 규칙

1. 배수로는 타일마다 원형 물결을 그리지 않는다. 연결된 수면 위에 2~6px 크기의 반사, 거품, 부유물과 가장자리 포말만 배치한다.
2. 흙은 단색 사각형 대신 2~4px 픽셀 군집, 지층선, 자갈과 굴착면 그림자를 좌표 해시로 배치한다.
3. 흙·물·통로·금속 외곽은 인접 타일이 같은 재질이면 생략하고 재질 경계에서만 밝은 면과 접지 그림자를 만든다.
4. 콘크리트와 작업대는 한 칸마다 액자를 두르지 않는다. 2~4칸 간격의 판 이음새, 볼트, 깨진 모서리와 제한된 황색 경고색만 사용한다.
5. 뿌리는 X 아이콘이 아니라 중심 줄기, 갈라지는 가지와 끝단으로 연결한다. 파괴 가능한 잔뿌리는 더 밝고 가늘게 표현한다.
6. 색은 청흑색 통로, 저채도 갈색 흙, 냉청록 물, 차콜 금속을 기본으로 하고 금광·경고등만 따뜻한 강조색을 사용한다.
7. 모든 디테일은 1~4px 정수 픽셀 군집으로 그린다. 큰 원, 매끈한 벡터 곡선, 동일 무늬 반복을 금지한다.

## 적용 범위

- Canvas 지형 렌더러의 흙·암반·열린 통로·깊은 물·얕은 물·뿌리·단차·경사로
- 맵 판정과 배치는 v2를 유지한다.
- 캐릭터, UI와 전투 규칙은 이번 개편 범위에서 변경하지 않는다.
