# 맵 디자인 인덱스

`서울 지하 999M`의 지형, 타일, 광맥, 매설물과 통로 바닥 시각 자료를 버전별로 보관한다.

## 현재 검토본

- `공통지형/콘셉트/v1/`: 공통 지형 비주얼 방향 v1
- 상태: 사용자 승인 전 디자인 초안
- 런타임 적용: 아직 적용하지 않음

## 보관 원칙

- 생성 원본과 승인된 런타임 타일을 구분한다.
- 콘셉트 이미지를 그대로 잘라 게임에 넣지 않는다.
- 논리 타일은 40×40px을 유지하되 인접 타일의 경계를 연결해 큰 흙덩어리처럼 보이게 만든다.
- 새 버전은 기존 폴더를 덮어쓰지 않고 `v2`, `v3`로 추가한다.
