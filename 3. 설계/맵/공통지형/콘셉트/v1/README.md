# 공통 지형 비주얼 콘셉트 v1

## 상태

- 분류: 디자인 초안
- 사용자 승인: 승인
- 실제 게임 적용: 40×40px Canvas 절차형 타일 v1 적용
- 기준 이미지: `seoul-999m-map-visual-concept-v1.png`

## 목표

- 현재의 반복되는 네모 상자 형태를 줄이고 인접한 흙 타일이 하나의 덩어리처럼 읽히게 한다.
- 어두운 지하 공포 분위기를 유지하면서도 열린 통로, 파괴 가능한 흙, 단단한 암반, 광맥과 매설 폭탄을 즉시 구분한다.
- 장식 밀도를 제한해 캐릭터와 전투 판정을 가리지 않는다.

## 구현 시 단순화 규칙

### 일반 흙

- 타일마다 사각 내부 테두리를 두지 않는다.
- 열린 통로와 맞닿은 외곽에만 밝은 흙 능선과 어두운 측면 그림자를 표시한다.
- 내부 변형은 자갈, 뿌리, 철근 조각을 합쳐 4종으로 제한한다.
- 장식이 차지하는 면적은 타일의 15%를 넘지 않는다.

### 단단한 암반

- 차가운 회색과 큰 판 균열을 사용한다.
- 일반 흙보다 명도 차이를 높이고 가장자리에 금속 볼트나 철판 흔적을 소량 배치한다.
- 균열 단계는 기존 내구도와 연동한다.

### 새로 메운 흙

- 일반 흙보다 한 단계 따뜻하고 밝은 압축 흙으로 표시한다.
- 삽자국 또는 눌린 발자국을 크게 1~2개만 사용한다.
- 생성 직후 모든 플레이어에게 약 1.5초간 보인 뒤 일반 흙 표현으로 자연스럽게 전환한다.

### 광맥과 크레딧

- 현재의 작은 노란 사각형을 사용하지 않는다.
- 금빛 광석과 고철 조각이 섞인 10~14px 덩어리로 표현한다.
- 획득 시 타일에서 `+크레딧` 피드백이 위로 짧게 떠오르며 HUD 자원 값과 동시에 갱신된다.

### 벽 매설 폭탄

- 적에게는 일반 흙과 완전히 동일하게 보인다.
- 설치한 팀에게만 10~12px 크기의 테이프 고정 장치와 짧은 전선이 보인다.
- 무장 전에는 약한 황색, 무장 후에는 낮은 빈도의 적색 1회 점멸을 사용한다.
- 광맥의 금빛 덩어리와 혼동되지 않도록 사각 금속 실루엣과 전선 형태를 유지한다.
- 콘셉트 시트의 큰 장치는 상태 설명용이며 실제 40px 타일에서는 축소한다.

### 열린 통로

- 완전한 검정 평면 대신 청흑색 콘크리트와 약한 배수 홈을 사용한다.
- 모든 칸에 선을 긋지 않고 2×2 또는 3×3 단위로 이음새를 끊는다.
- 흙 외곽의 어두운 접지 그림자로 통로 형태를 강조한다.
- 배수구, 파이프와 물 얼룩은 희소 장식으로만 배치한다.

## 게임 구성 순서

1. 40×40px 외곽 연결 규칙과 타일 마스크를 만든다.
2. 일반 흙·암반·새 흙·통로의 최소 변형 세트를 제작한다.
3. 내구도 균열을 오버레이로 분리한다.
4. 광맥과 아군 전용 폭탄 오버레이를 분리한다.
5. 크레딧 HUD와 획득 숫자 피드백을 정리한다.
6. 현재 전장에 적용하고 안개·대규모 교전에서 가독성을 검증한다.

## 런타임 반영 기록

- 2026-08-21: 논리 타일 크기 40px를 유지한 채 연결형 외곽선, 희소 바닥 이음새, 암반·광맥·새 흙·아군 폭탄 오버레이를 Canvas 절차형 렌더링으로 반영했다.
- 타일 변형은 좌표 해시를 사용해 프레임마다 흔들리지 않으며, 게임 판정과 시야 데이터는 변경하지 않는다.
- 새로 메운 흙은 생성 후 1.5초간 밝은 압축 흙과 삽자국을 표시한 뒤 일반 흙 명도로 전환한다.
